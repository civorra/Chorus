* Chorus::Frame — Knowledge representation
  :PROPERTIES:
  :CATEGORY: Component
  :SOURCE: lib/ (Chorus-Frame distribution, dependency)
  :END:

** Global registries

| Registry | Key | Value | Purpose |
|---|---|---|---|
| =%FMAP= | =_KEY= (MD5) | weak ref Frame | locate any Frame by key |
| =%REPOSITORY= | slot name | ={_KEY => 'Y', ...}= | which Frames provide this slot (used by =fmatch=) |
| =%INSTANCES= | parent =_KEY= | ={child_KEY => weak_ref}= | which Frames inherit from a given Frame |
| =%SERIAL= | =_SERIALIZE= value | =_KEY= | serialisation lookup |

All references in =%FMAP= and =%INSTANCES= are **weakened** (=weaken=) —
Frames are GC'd normally; =DESTROY= cleans up the registries.

** Special slots

| Slot | Role |
|---|---|
| =_KEY= | Unique MD5 identifier, assigned at creation — **never assign manually** |
| =_PARENT_KEY= | Set on inline sub-Frames for CoW |
| =_ISA= | Single Frame or arrayref of Frames — inheritance |
| =_VALUE= | Primary information target of the Frame |
| =_DEFAULT= | Fallback if =_VALUE= is absent |
| =_NEEDED= | Last-resort coderef — produces the value on demand (lazy eval) |
| =_BEFORE= | Hook before slot change |
| =_AFTER= | Hook after slot change (forward propagation) |
| =_REQUIRE= | Validation hook — returning =-1= blocks =set()= |
| =_NOFRAME= | Prevents automatic promotion of a hashref to a Frame |
| =_ALTERNATIVES= | List of alternative Frames for =fselect()= |
| =_ON_DELETE= | Hook triggered on Frame destruction |

** _REQUIRE semantics

=_REQUIRE= is a validation hook called before =set()=:

- Returning =-1= (or any false value) **cancels** the write — =set()= returns
  the constant =REQUIRE_FAILED=.
- If =_REQUIRE= blocks, =_BEFORE= and =_AFTER= are **not** called.
- =_REQUIRE= is inheritable via =_ISA= like any other slot.

#+begin_src perl
my $f = Chorus::Frame->new(
    _REQUIRE => sub { $SELF->get('_VALUE') > 0 ? 1 : -1 },
);
my $res = $f->set('_VALUE', -5);  # => REQUIRE_FAILED, _BEFORE/_AFTER not called
#+end_src

** _ON_DELETE semantics — cascade and $SELF

- Hook triggered on =delete($slot)= for that slot, or on Frame =DESTROY=.
- =$SELF= in =_ON_DELETE= is **always** the Frame on which =delete()= was called,
  even if a cascade triggers another Frame's =_ON_DELETE=.
- Modifications made inside =_ON_DELETE= (e.g. =set()= on another Frame)
  are immediately visible to =fmatch()= after the deletion.

#+begin_src perl
my $tracker = Chorus::Frame->new(count => { _VALUE => 0 });
my $f = Chorus::Frame->new(
    item       => 'x',
    _ON_DELETE => sub {
        $tracker->set('count', ($tracker->get('count') // 0) + 1);
    },
);
$f->delete('item');
# $tracker->get('count') == 1
# fmatch(slot => 'count') returns $tracker with count=1
#+end_src

** Inheritance modes N and Z

- **Mode N (default)**: for each valuation key (=_VALUE=, =_DEFAULT=, =_NEEDED=)
  in order, search the **entire inheritance tree** before moving to the next key.
- **Mode Z**: search the full sequence (=_VALUE=, =_DEFAULT=, =_NEEDED=) on each
  Frame before descending to its parents.

Switch with =Chorus::Frame::setMode(GET => 'Z')= / =setMode('N')=.

** get() path vs AUTOLOAD — $SELF semantics

Two ways to traverse a Frame hierarchy — different =$SELF= behaviour:

| Form | =$SELF= during traversal |
|---|---|
| =get('a b c')= | Stays on the **root frame** throughout |
| =->a->b->c= (chained AUTOLOAD) | **Moves** to each intermediate frame |

Also, =_NEEDED= is **not** evaluated on intermediate frames during =get('a b c')= —
only the terminal frame can trigger it.

#+begin_src perl
# Given A → B → C (via _ISA or sub-Frames)
# get('a b c') : $SELF = A throughout; _NEEDED of B not evaluated
# $a->a->b->c  : $SELF = A then B then C; _NEEDED of each step evaluated
#+end_src

⚠️ This distinction matters when an intermediate hook uses =$SELF= to
identify *which frame* it is running on.

** Copy-on-Write (CoW)

=set('a b c', $val)= creates local "shadow Frames" when traversing a Frame
whose =_PARENT_KEY= differs from the current Frame — prevents mutation of
shared sub-structures.

Explicitly available via =cow()= to duplicate a Frame before modification
(useful for simulation in a backward-chaining context).

** fmatch()

#+begin_src perl
fmatch(slot => 'name')             # all Frames providing 'name'
fmatch(slot => ['color', 'score']) # multi-slot intersection
fmatch(slot => 'color', from => \@list)  # restricted search space
#+end_src

Implemented via =%REPOSITORY= (direct providers) + =%INSTANCES= (inheritors) in BFS.
**O(1) complexity** for direct lookup.

⚠️ Only sees slots set via =set()= — not direct hash assignments.

*** Memoisation via =%FPS_CACHE= (since v2.0.x)

The result of =_framesProvidingSlot()= (the hot path of =fmatch()=) is cached
per slot in =%FPS_CACHE=:

#+begin_src perl
return $FPS_CACHE{$slot} if exists $FPS_CACHE{$slot};
# ... compute ...
$FPS_CACHE{$slot} = $result;
#+end_src

Invalidation guaranteed on every modification of that slot:

| Event | Invalidation |
|---|---|
| =set()= on a slot | =delete $FPS_CACHE{$slot}= via =_registerSlot= / =_register= |
| =delete()= of a slot | =delete $FPS_CACHE{$slot}= via =_unregisterSlot= |
| Frame =DESTROY= | =delete $FPS_CACHE{$slot}= for each slot carried |
| =_reset()= | =%FPS_CACHE = ()= — global reset |

The cache is always as fresh as an on-demand computation.
Benefit: repeated reads of the same slot with no risk of a stale result.

* Chorus::Engine — Inference engine

  :CATEGORY: Component

** Per-instance data structures

| Field | Type | Role |
|---|---|---|
| ={_RULES}= | arrayref of Frames | Master rule list |
| ={_QUEUE}= | arrayref | Working copy consumed by =applyrules()= |
| ={_CYCLE}= | int | Cycle counter (incremented in =loop()=) |
| ={_SUCCES}= | bool | At least one rule fired in the current =loop()= |
| ={_SLEEPING}= | flag | Set by =pause()=, cleared by =wakeup()= |
| ={_CUT}= | flag | Set by =cut()= |
| ={_LAST}= | flag | Set by =last()= |
| ={_REPLAY}= | flag | Set by =replay()= |
| ={_REPLAY_ALL}= | flag | Set by =replay_all()= |
| ={_IDENT}= | string | Agent name (debug) |
| ={_LOG}= | bool or coderef | Enables rule-firing log (evaluated at fire-time) |
| ={_MAX_CYCLES}= | int (default 10 000) | Inner loop guard |

** Rule Frame structure

#+begin_src perl
{
  _ID        => 'rule-name',         # optional — deduplication
  _SCOPE     => { var => sub {...} }, # scope combinators
  _APPLY     => sub { ... },         # action (plain coderef, not Frame dispatch)
  _TERMINAL  => 'solved'|'failed',   # optional — auto-terminate
  _PREMISSES => { slot => 'Y' },     # metadata, NOT used by applyrules()
  _TRACE     => 1,                   # optional — log each firing to STDERR
}
#+end_src

** _CYCLE and _SUCCES semantics

⚠️ Both fields are **reset to 0 at the start of each** =loop()= call:
#+begin_src perl
$SELF->{_SUCCES} = 0;
$SELF->{_CYCLE}  = 0;
#+end_src
=_CYCLE= holds the number of =applyrules()= passes in the current =loop()= call,
not a cumulative agent counter. See pitfalls.org §=_CYCLE=.

** _LOG and _TRACE mechanism (v2.0.2)

=addrule()= wraps each =_APPLY= in a logging closure. The presence of =_LOG=
is checked **at fire-time** — =_LOG= can be toggled dynamically after =addrule()=.
=_TRACE= is captured at registration time (immutable after =addrule()=).

** Public API methods

| Method | Description |
|---|---|
| =new(%opts)= | Creates a Frame inheriting from =$ENGINE= |
| =addrule(%rule)= | Adds a rule (with deduplication by =_ID=) |
| =loadRules($dir, %opts)= | Loads all =*.yml= files from a directory in alpha order |
| =loop()= | Inference loop until convergence or =_MAX_CYCLES= |
| =applyrules()= | One pass over all rules |
| =cut()= | Exits scope loops of the current rule |
| =last()= | Exits the current agent's rule queue |
| =replay()= | Restarts the current agent from the first rule |
| =replay_all()= | Restarts the entire pipeline from the first agent |
| =solved()= | Sets =BOARD->{SOLVED}= |
| =failed()= | Sets =BOARD->{FAILED}= |
| =pause()= / =wakeup()= | Disables / re-enables the engine |
| =reorder(\&cmp)= | Sorts =_RULES= then calls =replay()= |

** YAML → Perl compilation

=loadRules()= calls =codeRule()= on each YAML file then =eval=s the result:
#+begin_src perl
my $code = '$SELF->addrule(' . codeRule($SELF, readRule(file => $f)) . ');';
eval $code;
#+end_src

=codeRule()= produces the Perl text of the rule Frame, delegating to:
- =setScope()= — compiles a =FIND/CHERCHER= block into a =fmatch()= call
- =setFilter()= — compiles =filtre:= entries into =grep { ... }= (implicit AND)
- =setCondition()= — compiles =CONDITION:= (implicit OR on lists)
- =setException()= — compiles =EXCEPTION:= into =return if ...=
- =setEffect()= — compiles =EFFET/ACTION:= into =_APPLY= code

These methods have no-op =_DEFAULT= implementations — each agent can override
them to customise YAML compilation.

** loadRules() — Guard coherence check (v2.0.2)
   :PROPERTIES:
   :COMPONENT: Chorus::Engine
   :ADDED: 2026-08-03 (deep-chorus KB audit)
   :END:

Before compiling each YAML rule, =loadRules()= calls =_check_guard_coherence()=:
if the slot tested in =EXCEPTION: "defined $f->{X}"= is not among the slots
written by the same rule's =ACTION=, a =GUARD MISMATCH= warning is emitted.
Never raises =die= — backward compatibility guaranteed.

#+begin_example
[Chorus::Engine] GUARD MISMATCH in rule 'rule-name' (R05-xxx.yml)
  EXCEPTION tests : '$f->{slot_guard}'
  ACTION writes   : [slot_a, slot_b]
  Risk: if 'slot_guard' is pre-set in a project JSON, this rule is bypassed
  and [slot_a, slot_b] will never be computed.
  Suggested fix   : EXCEPTION: "defined $f->{slot_a}"
#+end_example

⚠️ **Implication for =chorus-create-project= cross / edges**:
pre-setting a rule's guard slot in a test project JSON bypasses ALL its
side-effects (=slot_a=, =slot_b= never computed).
→ Check =chorus-check.md §Step 5= and =chorus-feed.md §Guard= for the
slot guard selection rule.

* Chorus::Expert — Multi-agent orchestrator
  :PROPERTIES:
  :CATEGORY: Component
  :SOURCE: lib/Chorus/Expert.pm
  :END:

** Data structures

| Field | Type | Role |
|---|---|---|
| ={_agents}= | arrayref | Agents registered in execution order |
| ={_board}= | =Chorus::Frame= | Shared BOARD injected into each agent |
| ={_MAX_ITER}= | int (default 10 000) | =do/until= outer loop guard |

⚠️ These fields live on a plain **blessed hashref** (=bless {}, $class=),
**not** a Frame. Unlike =Chorus::Engine=, =Chorus::Expert= does not inherit from =$ENGINE=.

** process() behaviour — BOARD cleanup

⚠️ =process()= **deletes** =BOARD->{SOLVED}= and =BOARD->{FAILED}= before returning.
After the call, these slots are =undef= even if the pipeline succeeded.
Use the return value of =process()= (=1= / =undef=) — see pitfalls.org §=BOARD->{SOLVED}=.

** Public API methods

| Method | Description |
|---|---|
| =new()= | Creates the expert with an empty BOARD and empty agent list. **Ignores all arguments.** |
| =register(@agents)= | Injects BOARD and EXPERT back-ref into each agent |
| =process($input)= | Runs the do/until loop over agents; deletes SOLVED/FAILED from BOARD before returning |
| =debug($level)= | Enables internal STDERR traces (verbose — outer loop of =process()=) |

** Agent slots injected by register()

| Slot | Value | Access from rule |
|---|---|---|
| =BOARD= | reference to the shared BOARD | =$SELF->BOARD= or =$agent->BOARD= |
| =EXPERT= | reference to the Expert instance | =$SELF->EXPERT= |

** _LOCK_UNTIL_STABLE — agent synchronisation (v2.0.x)

An agent whose ={_LOCK_UNTIL_STABLE}= is true is **skipped** in any =process()=
iteration where at least one preceding agent has =_SUCCES= (fired ≥ 1 rule).

#+begin_src perl
my $b = Chorus::Engine->new(_IDENT => 'aggregator', _LOCK_UNTIL_STABLE => 'Y');
#+end_src

Behaviour in the =process()= loop:

#+begin_src
for my $agent (@agents):
    if $agent._LOCK_UNTIL_STABLE:
        last if any(@processed)._SUCCES   # ← agent skipped this iteration
    agent.loop()
    push @processed, $agent
#+end_src

Practical effect: the agent only runs when the system is "stable" —
when all upstream agents have exhausted their rules in this iteration.
Useful for final-aggregation agents that must not read partial results.

* Chorus::Frame — Inheritance Modes N & Z (v2.0.2)
  :PROPERTIES:
  :CATEGORY: Component
  :SUBSECTION: Frame Valuation
  :SOURCE: lib/Chorus/Frame.pm — _getN vs _getZ
  :END:

** Mode N (Default) — "breadth-first per valuation key"

Each valuation key (_VALUE, _DEFAULT, _NEEDED) is searched **across the entire
inheritance tree** before moving to the next key.

#+begin_src
Frame A:
  └─ _VALUE = 'v1'

Frame B (_ISA => A):
  └─ _DEFAULT = 'v2'

Frame C (_ISA => B):
  (no _VALUE, _DEFAULT, _NEEDED)

C.get(slot):
  1. search _VALUE on C, B, A → found 'v1' ✓
  2. return 'v1'
#+end_src

** Mode Z — "full sequence per frame"

Each Frame tests the full sequence (_VALUE → _DEFAULT → _NEEDED)
before descending to its parents.

#+begin_src
Frame A:
  └─ _VALUE = 'v1'

Frame B (_ISA => A):
  └─ _DEFAULT = 'v2'

Frame C (_ISA => B):
  (no _VALUE, _DEFAULT, _NEEDED)

C.get(slot):  [Mode Z]
  1. on C: _VALUE? no. _DEFAULT? no. _NEEDED? no.
  2. on B: _VALUE? no. _DEFAULT? 'v2' ✓
  3. return 'v2'  ← DIFFERENT from Mode N!
#+end_src

** Switching modes

#+begin_src perl
Chorus::Frame::setMode(GET => 'N');  # Mode N (default)
Chorus::Frame::setMode(GET => 'Z');  # Mode Z
Chorus::Frame::setMode('N');         # short form
#+end_src

The mode is a **global flag** — affects all Frames in the application.

* Chorus::Engine — Logging & Tracing (v2.0.2)
  :PROPERTIES:
  :CATEGORY: Component
  :SUBSECTION: Rule Execution Monitoring
  :SOURCE: lib/Chorus/Engine.pm — addrule(), _log_fire()
  :END:

** _LOG mechanism (agent-level)

=_LOG= is a slot on the engine Frame. It is checked **at fire-time**.

#+begin_src perl
# Before loop()
$agent->set('_LOG', 1);             # log to STDERR
$agent->set('_LOG', \&custom_handler);  # custom callback

# During loop()
if ($res) {  # rule fired
    my $log = $engine->{_LOG};
    _log_fire($engine, $rule_id, \%opts, $log) if $log;
}
#+end_src

Benefit: logging can be toggled **dynamically** without recompiling.

** _TRACE mechanism (rule-level)

=_TRACE= is captured at =addrule()= time (immutable afterwards).

#+begin_src perl
$agent->addrule(
    _ID => 'my-rule',
    _TRACE => 1,   # log to STDERR each time this rule fires
    ...
);
#+end_src

Or in YAML:
#+begin_src yaml
RULE: my-rule
TRACE: 1
...
#+end_src

** Wrapper closure injection (addrule implementation)

At =addrule()= time, if =_APPLY= exists, it is wrapped in a closure
that captures =_LOG= and =_TRACE=:

#+begin_src perl
my $orig_apply = $args{_APPLY};
my $engine = $SELF;
my $rule_id = $args{_ID};
my $do_trace = $args{_TRACE};

$args{_APPLY} = sub {
    my %opts = @_;
    my $res = $orig_apply->(%opts);  # call original _APPLY
    if ($res) {
        my $log = $engine->{_LOG} // ($do_trace ? 1 : undef);
        _log_fire($engine, $rule_id, \%opts, $log) if $log;
    }
    return $res;
};
#+end_src

This injection is **non-intrusive**: the wrapper is transparent to =_APPLY=.

** Custom handler for log4perl or other frameworks

#+begin_src perl
use Log::Log4perl qw(:easy);
Log::Log4perl->easy_init($DEBUG);

$agent->set('_LOG', sub {
    my ($engine, $rule_id, $opts) = @_;
    DEBUG sprintf "[cycle %s]  %s / %s  fired",
        $engine->{_CYCLE}, $engine->{_IDENT} // '?', $rule_id;
});
#+end_src

* Chorus::Engine::AIAgent — AI Pipeline (POD documentation)
  :PROPERTIES:
  :CATEGORY: Component
  :SOURCE: lib/Chorus/Engine/AIAgent.pod

This file is pure POD — no Perl code.
It documents the Phase A pipeline (corpus → KB + YAML rules).

** Three-layer architecture

1. **Corpus extraction** — =chorus-pdf= / =chorus-word= / =chorus-excel=
   → enriched text corpus (tables, figures, XREFs)

2. **Knowledge formalisation** (sole LLM phase) — =chorus-feed=
   → org-mode KB (ontology, frames, aliases) + YAML rules

3. **Deterministic execution** — =chorus-check= + =perl run.pl=
   → compliance report per element, per agent, with normative reference

** Associated skills (=$ENGINE/agent/skills/=)
=chorus-pdf=, =chorus-word=, =chorus-excel=, =chorus-feed=, =chorus-check=,
=chorus-create-project=, =chorus-import-project=, =chorus-strengthen=,
=chorus-quickstart=.
