*** Détail — Testing Tab, évolutions 2026-10-14 (commits =92c2e84=, =cfa059f=, =7528bd5=)
    :PROPERTIES:
    :SOURCE: chorus/scanner.js, chorus/reports.js
    :END:

- =chorus/scanner.js= tolère =project-*.json= (EN) **et** =projet-*.json= (FR)
  pour détecter les fichiers de test iso/edges/cross/scale.
- =chorus/reports.js::computeConvergenceFromRunReport()= — réapplique la
  convention de nommage =-OK-=/=-KO-= directement sur =elements[]= d'un
  =run-report-*.json= pour calculer les discordances sans exiger
  =chorus-check --all=. Fallback utilisé quand
  =.last-check-results.json= est absent ou ne couvre pas un fichier projet
  donné. Gère le verdict =NOT_CHECKED= distinctement de (non traité).
- Invalidation de run obsolète : comparaison du mtime du fichier projet
  avec le =generated_at= du dernier run-report correspondant — si le
  fichier a été régénéré (⟲) après son dernier run connu, ce run-report est
  jugé périmé et écarté (=lastRun=/=convergence= → =null=, "Jamais exécuté").
  Nouveau champ =fileDate= (mtime du fichier projet) + date+heure complète
  (au lieu de date seule) sur =lastRun.date=.
- =refreshSandboxReports()= re-render désormais aussi l'onglet Tests s'il
  est actif ; =levelTerminalExec= post-run refresh couvre également les
  terminaux de niveau =sandbox= (utilisé par =runTestingStrategy=).
- Garde de concurrence : une seule session terminal de =kind= =strengthen=
  par sandbox à la fois, timeout plafonné à 45 min (cf.
  =webapp-architecture.org= / section Terminal ECA pour le détail serveur).

*** Évolutions 2026-10-13/14 (commits =729a1f8=, =7528bd5=, =7e76478=)

- **Routage explicite skill → agent** (=729a1f8=) : le champ =agent= du body
  =/prompt= REST n'a aucun effet (chat reste sur =defaultAgent=) — le vrai
  mécanisme est la route non documentée =POST /api/v1/chats/:id/agent= (204,
  persiste durablement). =eca-client.js= expose =setChatAgent(chatId, agent)=
  (best-effort). =terminal.js= : table =AGENT_BY_TRIGGER= miroir du mapping
  Trigger→Skill→Agent d'=Engine/AGENTS.md=, =detectExpectedAgent()= par
  keyword matching, appelée avant l'envoi du prompt. Gère la race condition
  nouveau-chat (route =/agent= 404 tant que le chat n'est pas matérialisé par
  le premier =/prompt=) via prompt fire-and-forget + court délai + =setChatAgent=.
- **Bannière skill actif** (=729a1f8=) : =classifyToolCall()= extrait désormais
  =isSkillLoad=/=skillName= depuis les arguments de l'outil =skill= — correction
  d'un bug où =TOOL_FAMILIES= ne matchait jamais rien (ECA émet les noms
  d'outils bruts, sans préfixe =eca__=, en remote), tous les tool calls
  retombaient silencieusement sur la famille générique ⚙. =terminal.js= suit
  =currentSkill=/=skillHistory= par session, émet un événement SSE =skill=
  dédié ; bannière persistante sous le titlebar du terminal.
- **Live task board** (=729a1f8=) : =eca__task= retourne déjà l'état consolidé
  (tasks/summary/activeSummary) à chaque appel plan/start/complete —
  =classifyToolCall()= l'expose via =isTaskUpdate=/=taskboard=, sans
  reconstruction manuelle. Événement SSE =taskboard= dédié ; panneau checklist
  repliable (☐/⏳/☑), mis à jour en direct.
- **Visibilité sub-agents parallèles** (=729a1f8=) : les tool calls internes
  d'un sub-agent (ses propres grep/read_file pendant que =spawn_agent=
  s'exécute) sont émis par ECA sous un =chatId= **séparé**
  (=subagent-<toolCallId>=), invisible à qui ne surveille que le =chatId=
  parent. =eca-client.js::subscribeEcaEvents()= élargit désormais
  dynamiquement son watch set à chaque =subagentChatId= révélé par un
  toolCallRun =spawn_agent=, relaie via le callback =onSubagentToolLog()=.
  =terminal.js= relaie via un événement SSE =subagent-tool=, historique
  persistant par session. UI : section DOM repliable dédiée par sub-agent.
- **Garde de concurrence terminal** (=7528bd5=) : interdiction de plus d'une
  session terminal de =kind= =strengthen= par sandbox à la fois (vérifiée
  côté serveur avant contact avec =eca-server=) — timeout par défaut plafonné
  à 45 min (au lieu de 60) pour =chorus-strengthen=. =kind= fourni
  explicitement par le bouton "🔧 Renforcer" dédié de l'onglet Tests, jamais
  inféré d'une saisie libre.
- **Health-check robuste** (=7e76478=) : cf. § *Pattern SSE — Bug Jetty
  eca-server* dans =webapp-architecture.org= (=promptAndWaitSSE()=,
  =pingTcp()=).
