* Statuts

- =proposed=   : identifié, en attente de rédaction formelle (ENG-065)
- =accepted=   : rédigé, relu, commité
- =deprecated= : remplacé par une approche différente (sans successeur direct)
- =superseded-by ADR-NNN= : remplacé par un ADR plus récent

* Conventions

- Un ADR = un fichier =ADR-NNN.org= dans ce répertoire.
- Un ADR accepté ne se modifie pas — il se remplace par un nouvel ADR (statut =superseded-by=).
- Référencer depuis les commits : =feat(...): ... — See ADR-NNN=
- Référencer depuis les YAML rules : =# Design: See ADR-NNN (<raison courte>)=
- Référencer depuis =pitfalls.org= : property =:ADR: ADR-NNN=
