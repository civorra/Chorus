* Statuts

- =proposed=   : identifié, en attente de rédaction formelle
- =accepted=   : rédigé, relu, commité
- =deprecated= : remplacé par une approche différente (sans successeur direct)
- =superseded-by ADR-NNN= : remplacé par un ADR plus récent

* Conventions de référencement

- Depuis commits git : =feat(...): ... — See ADR-NNN=
- Depuis YAML rules  : =# Design: See ADR-NNN (<raison courte>)=
- Depuis =pitfalls.org= : property =:ADR: ADR-NNN=
- Depuis skills     : ="See ADR-NNN."= dans le texte d'instruction
