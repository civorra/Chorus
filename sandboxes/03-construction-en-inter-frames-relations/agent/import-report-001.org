*** External walls

      ~building_ref~: RES-01 = 3 storeys, RES-02 = 2 storeys. Added to all external wall
      and internal wall frames in the JSON. This is a gap in the source document that was
      resolved by cross-reference.
    - All other mandatory slots (wall_type, thickness_mm, height_m, length_m, storey_height_m,
      storey_position, masonry_unit_type, masonry_material, masonry_group,
      declared_strength_nmm2, mortar_designation, soil_type, shrink_class, wall_load_kn_m,
      foundation_width_mm, foundation_depth_m, foundation_thickness_mm, projection_p_mm)
      are present for all external wall frames. ✅

*** Internal walls
    - ~num_storeys_building~ not in source — inferred from ~building_ref~. Added as above.
    - All other mandatory slots (thickness_mm, storey_height_m, storey_position, building_ref)
      present. ✅

*** Parapet walls
    - ~num_storeys_building~ absent (not required by parapet pipeline — masonry R01 for parapets
      always gives Condition A; parapet_wall frame does not need this slot). ✅
    - All mandatory slots for parapet_wall present. ✅

*** Buttressing walls
    - ~height_m~ of supported wall: the HTML provides ~buttressing_length_m~ and ~supports_ref~
      but does NOT include the height of the supported wall directly in the buttressing section.
      The buttressing_wall KB frame requires ~height_m~ for the R05 check (H/6 minimum length).
      ⚠ UNRESOLVED GAP: height_m not set on buttressing_wall frames in the JSON.
      Resolution: Wall R05 in Chorus reads h = $w->{height_m} // 0 → if height_m is absent,
      h=0, min_len=0, buttressing check trivially passes (even BW-KO-LEN-01 would show OK).
      The source document documents the compliance verdict explicitly — the pipeline will need
      height_m to reproduce the correct check.
      Recommendation: Add height_m from the referenced external wall (via supports_ref lookup)
      to each buttressing_wall frame. Values:
      - BW-01 → supports EW-B-01 → height_m: 3.2
      - BW-02 → supports EW-B-02 → height_m: 3.2
      - BW-03 → supports EW-B-06 → height_m: 3.0
      - BW-04 → supports EW-T-01 → height_m: 3.0
      - BW-05 → supports EW-B-07 → height_m: 3.0
      - BW-06 → supports EW-T-05 → height_m: 3.0
      - BW-KO-LEN-01 → supports EW-B-01 → height_m: 3.2

*** Chimney frames

      present. ✅
