* Domain
  Geometric verification of building proportions and classification.
  This agent handles the upstream checks defined in sections 2C1, 2C4, 2C6,
  2C14 and 2C16 of Approved Document A:

  - Identifies the building type (residential, non-residential, annexe)
  - Verifies H ≤ 15m, H ≤ 2×W1 proportions for residential buildings
  - Verifies H ≤ 3m / W ≤ 9m for single-storey non-residential buildings
  - Verifies H ≤ 3m or 4.5m for annexes
  - Verifies max floor area (70m² / 36m²)
  - Calculates wind exposure via Diagram 7 (Factor S → max height)
  - Sets the targeting slot for downstream agents (Wall, Masonry, Foundation)

  Pipeline position 1/4 — no dependency on previous agents.

* Targeting Slots                                                        :SCOPE:
  /This agent is the first in the pipeline. Frames are populated by the initial/
  /JSON feed. The targeting slot is set by the feed on every submitted element./

** Chosen Strategy
   Strategy A — discriminating slot value.
   The feed sets ~type_element~ on every Frame. This agent filters on type
   values belonging to the geometric perimeter.
   Frame volume is expected to remain well below 50 → Strategy A is safe.

   Justification   : small volume (typically 1 building + 4–8 walls + 1 floor + 1 roof);
                     ~type_element~ is set by the feed on every Frame from the outset;
                     direct filter avoids the overhead of a dedicated presence slot.

* Rule Catalogue
** Rule: R01-residential-geometry
   Intent    : Verify all geometric constraints for residential buildings (§2C4a, §2C14, §2C16)
               and set the besoin_wall targeting slot.
   Priority  : 1

   FIND      :
   - ~b~ → attribut: ~type_element~  [filtre: ~'$_->{type_element} eq "residential_building"'~]

   EXCEPTION : ~defined $b->{geometry_ok}~
   CONDITION : –
   EFFECT    :
   #+BEGIN_SRC perl
   use ADA::Agent::Geometry::Helpers qw(max_height_from_table_c);
   my @violations;

   # Check: storeys ≤ 3 and H ≤ 15m
   my $h          = $b->{height_m} // 0;
   my $storeys    = $b->{num_storeys} // 0;
   my $w1         = $b->{width_w1_m} // 0;
   my $floor_area = $b->{floor_area_m2} // 0;

   push @violations, "storeys > 3 (got $storeys)"  if $storeys > 3;
   push @violations, "height_m > 15 (got ${h}m)"   if $h > 15;

   # Check: H ≤ 2×W1 (§2C4a-ii)
   my $prop_ok = ($w1 > 0 && $h <= 2 * $w1) ? 'YES' : 'NO';
   push @violations, "H > 2×W1 (H=${h}m, W1=${w1}m)" if $prop_ok eq 'NO';

   # Check: floor area ≤ 70m² (§2C14)
   my $area_ok = ($floor_area <= 70) ? 'YES' : 'NO';
   push @violations, "floor_area > 70m² (got ${floor_area}m²)" if $area_ok eq 'NO';

   # Check: wing proportions if wing present (§2C4a-iii)
   my $p  = $b->{projection_p_m} // 0;
   my $w2 = $b->{width_w2_m}    // 0;
   my $h2 = $b->{height_wing_h2_m} // 0;
   if ($p > 0 && $w2 > 0 && $p > 2 * $w2) {
       push @violations, "wing H2 > 2×W2 (H2=${h2}m, W2=${w2}m)"
           if $h2 > 2 * $w2;
   }

   # Wind height limit from Table c Diagram 7 (§2C16)
   my $max_h = max_height_from_table_c(
       $b->{factor_s}, $b->{site_type}, $b->{coast_distance_km}
   );
   $max_h = 15 unless defined $max_h;  # default cap
   push @violations, "height_m > max_wind_height (${h}m > ${max_h}m)" if $h > $max_h;

   my $geo_ok = @violations ? 'NO' : 'YES';

   $b->set('storey_height_ok',    ($h <= 15 && $storeys <= 3) ? 'YES' : 'NO');
   $b->set('proportion_ok',       $prop_ok);
   $b->set('floor_area_ok',       $area_ok);
   $b->set('max_height_allowed_m', $max_h);
   $b->set('geometry_violations', join('; ', @violations));
   $b->set('geometry_ok',         $geo_ok);
   $b->set('besoin_wall',         'Y');
   1
   #+END_SRC

   Notes: max_height_from_table_c() returns undef if factor_s/site_type not provided →
          defaults to 15m. Wing check only activates when P > 0 and W2 > 0.

** Rule: R02-non-residential-geometry
   Intent    : Verify geometric constraints for small non-residential buildings (§2C4b).
   Priority  : 2

   FIND      :
   - ~b~ → attribut: ~type_element~  [filtre: ~'$_->{type_element} eq "non_residential_building"'~]

   EXCEPTION : ~defined $b->{geometry_ok}~
   EFFECT    :

   use ADA::Agent::Geometry::Helpers qw(max_height_from_table_c);

   my $h     = $b->{height_m} // 0;
   my $w     = $b->{width_m}  // 0;
   my $area  = $b->{floor_area_m2} // 0;

   # §2C4b: H ≤ 3m

** Rule: R03-annexe-geometry
   Intent    : Verify geometric constraints for annexes (§2C4c, §2C14).
   Priority  : 3

   FIND      :
   - ~b~ → attribut: ~type_element~  [filtre: ~'$_->{type_element} eq "annexe"'~]

   EXCEPTION : ~defined $b->{geometry_ok}~
   EFFECT    :
   #+BEGIN_SRC perl
   use ADA::Agent::Geometry::Helpers qw(max_height_from_table_c);
   my @violations;

   my $h         = $b->{height_m}    // 0;
   my $roof_type = $b->{roof_type}   // 'flat';
   my $area      = $b->{floor_area_m2} // 0;

   # §2C4c: max H = 3m (flat) or 4.5m (pitched ≤40°)
   my $max_h_type = ($roof_type eq 'pitched') ? 4.5 : 3.0;
   push @violations, "height_m > ${max_h_type}m for $roof_type roof (got ${h}m)"
       if $h > $max_h_type;

   # §2C14: floor area ≤ 36m²
   push @violations, "floor_area > 36m² (got ${area}m²)" if $area > 36;

   # Wind height limit
   my $max_h_wind = max_height_from_table_c(
       $b->{factor_s}, $b->{site_type}, $b->{coast_distance_km}
   );
   if (defined $max_h_wind) {
       my $effective_max = ($max_h_type < $max_h_wind) ? $max_h_type : $max_h_wind;
       push @violations, "height_m > wind limit (${h}m > ${max_h_wind}m)"
           if $h > $max_h_wind;
       $b->set('max_height_allowed_m', $effective_max);
   } else {
       $b->set('max_height_allowed_m', $max_h_type);
   }

   $b->set('geometry_violations', join('; ', @violations));
   $b->set('geometry_ok',         @violations ? 'NO' : 'YES');
   $b->set('besoin_wall',         'Y');
   1
   #+END_SRC

* Perl Helpers
** max_height_from_table_c
   Signature   : ~sub max_height_from_table_c($factor_s, $site_type, $coast_km) → $height_m | undef~
   Description : Returns the maximum allowable building height in metres from Table c of
                 Diagram 7, given wind Factor S, site type ('country'/'town'), and distance
                 to coast in km. Returns undef if factor_s is not provided.
                 Corrected value: Factor S=34, country >50km = 8.5m (PDF source defect: was 87.5).
   Called by   : R01-residential-geometry, R02-non-residential-geometry, R03-annexe-geometry
   Exported    : yes — add to @EXPORT_OK
   Notes       : Interpolation not implemented (conservative: use lower bound).
                 Empty cells in Table c (Factor S too high for that exposure) → returns undef
                 (site is out of scope of this guidance).

   #
   # Structure: $TABLE_C{$site_type}{$coast_band}[$factor_s - 25]

* Constraints & Pitfalls
  - [ ] ~type_element~ must use exact values 'residential_building', 'non_residential_building', 'annexe'
        — any typo silently produces 0 processed Frames (filtre fails)
  - [ ] R01/R02/R03 EXCEPTION on ~geometry_ok~ ensures idempotence — mandatory
  - [ ] ~max_height_from_table_c~ returns ~undef~ for Factor S > 44 or for cells marked
        empty in Table c → calling code must handle undef (default to type-specific cap)
  - [ ] Wing check (R01) activates only when P > 0 and W2 > 0 — if omitted from JSON the
        wing check is simply skipped (safe default)
  - [ ] ~besoin_wall~ = 'Y' must be set even if geometry_ok = 'NO' — downstream agents
        still need to process the walls (to produce a complete non-conformance report)
  - [ ] Table c values: Factor S index = factor_s − 25 (S=25 → index 0, S=44 → index 19)
  - [ ] Country/town boundary: sites < 300m from town edge → treated as country terrain
        (Table c Note i) — this must be handled at feed time, not by this agent
  - [ ] _MAX_CYCLES recommended: 3 Frames × 3 rules × 4 agents × 10 = 360 (default 10000 is fine)
  - [ ] ⚠️ _CYCLE and _SUCCES are reset to 0 at the start of every loop() call — do not use
        them as cumulative counters across loop() calls. To accumulate a global total,
        write to a dedicated BOARD slot from within a rule.
