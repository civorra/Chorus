* Domain
  Verification of strip foundation sizing per Table 10 of Approved Document A,
  and ground suitability per §2E1–2E4:

  - Verifies minimum width of strip footings (Table 10) for soil types I–VII
    and total load of load-bearing walling (kN/linear metre)
  - Verifies minimum depth of strip foundations (§2E4): 0.45m general,
    0.75m/0.9m/1.0m for shrinkable clays
  - Verifies minimum concrete thickness T ≥ 150mm or P (§2E2c)
  - Verifies that soil type V/VI load does not exceed 30kN/m (Table 10 note)
  - Excludes soil type VII (refers to specialist advice)
  - Marks overall foundation verdict and terminates the pipeline via solved()

  Pipeline position 4/4 (terminal) — depends on ADA::Agent::Masonry having set
  ~besoin_foundation~ on the relevant external wall Frames.

* Rule Catalogue
** Rule: R01-foundation-width
   Intent    : Verify strip foundation width meets Table 10 minimum for the given
               soil type and wall load. Handles soil type I (rock = wall width),
               out-of-scope loads for types V/VI (> 30kN/m), and type VII (specialist).
   Priority  : 1

   FIND      :
   - ~f~ → attribut: ~besoin_foundation~

   EXCEPTION : ~defined $f->{foundation_width_ok}~
   EFFECT    :
   #+BEGIN_SRC perl
   use ADA::Agent::Foundation::Helpers qw(min_width_table10);
   my @violations;

   my $soil  = $f->{soil_type}         // 'II';
   my $load  = $f->{wall_load_kn_m}    // 0;
   my $width = $f->{foundation_width_mm} // 0;

   # Soil type VII → specialist advice required (§2E1 / Table 10)
   if ($soil eq 'VII') {
       push @violations, "soil type VII: specialist advice required (Table 10)";
       $f->set('min_foundation_width_mm', 0);
       $f->set('foundation_width_ok',     'NO');
       $f->set('foundation_violations',   join('; ', @violations));
       return 1;
   }

   # Soil types V/VI: load > 30kN/m → out of scope (Table 10 note)
   if ($soil =~ /^(V|VI)$/ && $load > 30) {
       push @violations,
           "soil type $soil: load ${load}kN/m > 30kN/m limit (Table 10 note — outside scope)";
       $f->set('min_foundation_width_mm', 0);
       $f->set('foundation_width_ok',     'NO');
       $f->set('foundation_violations',   join('; ', @violations));
       return 1;
   }

   my $min_w = min_width_table10($soil, $load);

   if (!defined $min_w) {
       # Soil type I (rock) → width = wall width (not stored here — flag as 'YES')
       $f->set('min_foundation_width_mm', 0);   # 0 = wall width (rock = equal to wall)
       $f->set('foundation_width_ok',     'YES');
   } elsif ($width < $min_w) {
       push @violations,
           "foundation_width ${width}mm < min ${min_w}mm (Table 10, soil $soil, load ${load}kN/m)";
       $f->set('min_foundation_width_mm', $min_w);
       $f->set('foundation_width_ok',     'NO');
   } else {
       $f->set('min_foundation_width_mm', $min_w);
       $f->set('foundation_width_ok',     'YES');
   }

   $f->set('foundation_violations', join('; ', @violations));
   1
   #+END_SRC

   Notes: Soil type I (rock) → min width = wall width (no numeric minimum); returns
          min_foundation_width_mm = 0 as sentinel with verdict 'YES'.

** Rule: R02-foundation-depth
   Intent    : Verify minimum depth of strip foundations per §2E4 (frost and shrinkage).
   Priority  : 2

   FIND      :
   - ~f~ → attribut: ~besoin_foundation~

   EXCEPTION : ~defined $f->{foundation_depth_ok}~
   EFFECT    :
   #+BEGIN_SRC perl
   use ADA::Agent::Foundation::Helpers qw(min_depth_2e4);
   my @viol = split /;\s*/, ($f->{foundation_violations} // '');

   my $shrink = $f->{shrink_class}     // 'none';
   my $depth  = $f->{foundation_depth_m} // 0;

   my $min_d = min_depth_2e4($shrink);

   if ($depth < $min_d) {
       push @viol,
           "foundation_depth ${depth}m < min ${min_d}m (§2E4, shrink_class=$shrink)";
       $f->set('foundation_depth_ok', 'NO');
   } else {
       $f->set('foundation_depth_ok', 'YES');
   }

   $f->set('foundation_violations', join('; ', @viol));
   1
   #+END_SRC

** Rule: R03-foundation-thickness
   Intent    : Verify concrete foundation thickness T ≥ 150mm or P (§2E2c),
               then set the overall foundation verdict.
   Priority  : 3

   FIND      :
   - ~f~ → attribut: ~besoin_foundation~

   EXCEPTION : ~defined $f->{foundation_ok}~
   CONDITION : ~defined $f->{foundation_width_ok} && defined $f->{foundation_depth_ok}~
   EFFECT    :
   #+BEGIN_SRC perl
   my @viol = split /;\s*/, ($f->{foundation_violations} // '');

   my $T  = $f->{foundation_thickness_mm} // 0;
   my $P  = $f->{projection_p_mm}         // 0;

   # §2E2c: T ≥ 150mm or P, whichever is greater
   my $min_T = ($P > 150) ? $P : 150;
   if ($T < $min_T) {
       push @viol,
           "foundation_thickness ${T}mm < min ${min_T}mm (§2E2c, T≥150mm or P)";
       $f->set('foundation_thickness_ok', 'NO');
   } else {
       $f->set('foundation_thickness_ok', 'YES');
   }

   # Overall verdict
   my $ok = ($f->{foundation_width_ok} eq 'YES'
          && $f->{foundation_depth_ok}  eq 'YES'
          && @viol == 0)
          ? 'YES' : 'NO';

   $f->set('foundation_violations', join('; ', @viol));
   $f->set('foundation_ok',         $ok);
   1
   #+END_SRC

   Notes: CONDITION ensures R01 and R02 have already fired. The overall verdict
          aggregates all three sub-checks. Pipeline termination is handled by a
          pure-Perl addrule() in the shell Agent (not in YAML — avoids infinite loop).

** Rule: R04-a-stepped-foundation
   Intent    : Verify that stepped (or trench fill) foundations comply with §2E2d-e:
               - Overlap L ≥ max(2×S, T, 300mm) for strip foundations (§2E2d)
               - Overlap L ≥ max(2×S, 1000mm) for trench-fill foundations (§2E2d note)
               - Step height S ≤ T (§2E2e)
               Only fires when step_height_mm is present in the feed.
   Priority  : 4

   FIND      :
   - ~f~ → attribut: ~besoin_foundation~  [filtre: ~'defined $_->{step_height_mm}'~]

   EXCEPTION : ~defined $f->{stepped_foundation_ok}~
   EFFECT    :
   #+BEGIN_SRC perl
   my @viol = split /;\s*/, ($f->{foundation_violations} // '');

   my $S    = $f->{step_height_mm}        // 0;   # step height
   my $T    = $f->{foundation_thickness_mm} // 0; # foundation thickness
   my $L    = $f->{foundation_overlap_mm} // 0;   # actual overlap
   my $ftyp = $f->{foundation_type}       // 'strip';

   # §2E2e: step height S ≤ T (foundation thickness)
   if ($T > 0 && $S > $T) {
       push @viol, "step height S=${S}mm > foundation thickness T=${T}mm (§2E2e)";
   }

   # §2E2d: minimum overlap
   if ($L > 0) {
       my $min_L;
       if ($ftyp eq 'trench_fill') {
           # Trench fill: L ≥ max(2×S, 1000mm)
           $min_L = ($S * 2 > 1000) ? $S * 2 : 1000;
       } else {
           # Strip: L ≥ max(2×S, T, 300mm)
           $min_L = $S * 2;
           $min_L = $T   if $T > $min_L;
           $min_L = 300  if 300 > $min_L;
       }
       if ($L < $min_L) {
           push @viol,
               "foundation overlap L=${L}mm < min ${min_L}mm (§2E2d, $ftyp, S=${S}mm, T=${T}mm)";
       }
   }

   my $ok = @viol ? 'NO' : 'YES';
   $f->set('stepped_foundation_ok', $ok);
   $f->set('foundation_violations', join('; ', @viol));
   1
   #+END_SRC

   Notes: Fires only when step_height_mm is provided — flat foundations skip this rule.
          §2E2d also requires stepped foundations to unite at each change in level
          (Diagram 21) — this is a constructional requirement not verifiable from dimensions alone.
          foundation_type defaults to 'strip' if not provided in the JSON feed.

* Perl Helpers
** min_width_table10
   Signature   : ~sub min_width_table10($soil_type, $load_kn_m) → $mm | undef~
   Description : Returns minimum strip foundation width in mm from Table 10.
                 Returns undef for soil type I (rock — width = wall width per Table 10).
                 Returns undef for soil type VII (specialist advice).
                 Returns undef for types V/VI when load > 30kN/m (out of scope).
                 Interpolation: uses the minimum column whose load threshold ≥ actual load.
   Called by   : R01-foundation-width
   Exported    : yes — add to @EXPORT_OK
   Notes       : Table 10 load columns: 20 / 30 / 40 / 50 / 60 / 70 kN/m.
                 Conservative approach: round up to nearest column.

   #+BEGIN_SRC perl
   # Table 10 — Minimum width of strip footings (mm)
   # Source corpus: Table 10 (p.39)
   #
   # Load columns (kN/linear metre): 20, 30, 40, 50, 60, 70
   # Soil I   (rock)       : width = wall width (all loads) → undef
   # Soil II  (gravel/sand): 250, 300, 400, 500, 600, 650
   # Soil III (stiff clay) : 250, 300, 400, 500, 600, 650
   # Soil IV  (firm clay)  : 300, 350, 450, 600, 750, 850
   # Soil V   (loose sand) : 400, 600, n/a, n/a, n/a, n/a  (max load 30kN/m per note)
   # Soil VI  (soft)       : 450, 650, n/a, n/a, n/a, n/a  (max load 30kN/m per note)
   # Soil VII (very soft)  : specialist advice → undef
   my @LOADS = (20, 30, 40, 50, 60, 70);
   my %TABLE10 = (
     I   => [undef, undef, undef, undef, undef, undef],  # rock = wall width
     II  => [250,   300,   400,   500,   600,   650  ],
     III => [250,   300,   400,   500,   600,   650  ],
     IV  => [300,   350,   450,   600,   750,   850  ],
     V   => [400,   600,   undef, undef, undef, undef],  # >30kN/m out of scope
     VI  => [450,   650,   undef, undef, undef, undef],  # >30kN/m out of scope
     VII => [undef, undef, undef, undef, undef, undef],  # specialist advice
   );
   #+END_SRC

** min_depth_2e4
   Signature   : ~sub min_depth_2e4($shrink_class) → $metres~
   Description : Returns minimum depth to underside of strip foundation (metres) per §2E4.
                 Standard minimum: 0.45m (frost protection).
                 Shrinkable clay overrides: low=0.75m, medium=0.9m, high=1.0m.
   Called by   : R02-foundation-depth
   Exported    : yes — add to @EXPORT_OK
   Notes       : §2E4 states these depths "may need to be increased" near trees —
                 this helper returns the regulatory floor only; site-specific
                 adjustments must be applied at feed time.

   #+BEGIN_SRC perl
   # §2E4 — Minimum depth of strip foundations
   # Source corpus: §2E4 (p.37)
   # none / non-clay  : 0.45m (frost depth)
   # low shrinkage    : 0.75m (Modified Plasticity Index 10–20%)
   # medium shrinkage : 0.90m (Modified Plasticity Index 20–40%)
   # high shrinkage   : 1.00m (Modified Plasticity Index ≥ 40%)
   my %MIN_DEPTH = (
     none   => 0.45,
     low    => 0.75,
     medium => 0.90,
     high   => 1.00,
   );
   #+END_SRC

* Constraints & Pitfalls
  - [ ] R03 CONDITION checks that R01 and R02 have both fired — if either is missing
        (EXCEPTION already set from a previous cycle) R03 returns early safely via CONDITION
  - [ ] Soil type VII → R01 sets foundation_width_ok = 'NO' and returns early; R02/R03
        still fire on the Frame (EXCEPTION on their own slots not yet set) — this is correct:
        depth and thickness checks remain independent
  - [ ] Load > 70kN/m is not covered by Table 10 — the feed must pre-validate this limit
        before submission; min_width_table10 returns undef for loads exceeding 70kN/m
  - [ ] Type I (rock): min_foundation_width_mm = 0 is a sentinel meaning "width = wall width";
        calling code must interpret 0 correctly — do NOT compare as 0mm minimum
  - [ ] Pipeline termination: this is the terminal agent — the shell Agent's addrule()
        must call $agent->solved() after all foundation Frames carry foundation_ok;
        do NOT use a YAML termination rule with global fmatch (→ infinite loop)
  - [ ] shrink_class default 'none' in R02: if the feed omits shrink_class for a clay soil,
        only the frost-depth minimum (0.45m) is checked — this may underestimate required
        depth for shrinkable clays; the feed should explicitly set shrink_class = 'none'
        for non-clay soils
  - [ ] Projection P in §2E2c: if foundation_p_mm is omitted from JSON → P defaults to 0 →
