* Domain
  Verification of masonry chimney proportions per Section 2D of Approved Document A:

  - Verifies that unsupported chimney height H does not exceed 4.5 × least width W (§2D1)
  - Applies only when masonry density > 1500 kg/m³
  - H measured from highest intersection with roof surface to top of chimney pot/flue terminal
  - W = least horizontal dimension of chimney measured at roof intersection

  Pipeline position 5/5 (optional terminal) — operates independently of other agents.
  May run in parallel with or after ADA::Agent::Foundation.

* Rule Catalogue
** Rule: R01-chimney-proportion
   Intent    : Verify masonry chimney height H ≤ 4.5 × least width W (§2D1).
               Only applies when masonry density > 1500 kg/m³.
               If density ≤ 1500 kg/m³ → flag for specialist design (§2D1 precondition).
   Priority  : 1

   FIND      :
   - ~c~ → attribut: ~type_element~  [filtre: ~'($_->{type_element}//"") eq "masonry_chimney"'~]

   EXCEPTION : ~defined $c->{chimney_ok}~
   EFFECT    :
   #+BEGIN_SRC perl
   my @violations;

   my $H       = $c->{chimney_height_m}      // 0;
   my $W       = $c->{chimney_least_width_m}  // 0;
   my $density = $c->{masonry_density_kg_m3}  // 1600;  # assume compliant if not stated

   # §2D1 precondition: density > 1500 kg/m³
   if ($density <= 1500) {
       push @violations,
           "masonry_density ${density}kg/m³ ≤ 1500 kg/m³ — §2D1 does not apply; specialist design required";
       $c->set('chimney_proportion_ok', 'NO');
       $c->set('chimney_violations',    join('; ', @violations));
       $c->set('chimney_ok',            'NO');
       return 1;
   }

   # §2D1: H ≤ 4.5W
   if ($W > 0) {
       my $max_h = 4.5 * $W;
       push @violations, "chimney H ${H}m > 4.5×W = ${max_h}m (§2D1, W=${W}m)"
           if $H > $max_h;
   } else {
       push @violations, "chimney_least_width_m missing — cannot verify §2D1 (H=${H}m)";
   }

   $c->set('chimney_proportion_ok', @violations ? 'NO' : 'YES');
   $c->set('chimney_violations',    join('; ', @violations));
   $c->set('chimney_ok',            @violations ? 'NO' : 'YES');
   1
   #+END_SRC

   Notes: Default density 1600 kg/m³ (standard clay brick) — safe assumption when not stated.
          §2D1 applies to chimneys "not adequately supported by ties or securely restrained";
          tied/restrained chimneys are outside scope of this rule — feed must pre-classify.

* Constraints & Pitfalls
  - [ ] density default: if masonry_density_kg_m3 absent → assumed > 1500 (standard brick);
        lightweight or low-density blocks may actually fail the precondition — feed should always
        provide the density for non-standard masonry
  - [ ] §2D1 applies only to chimneys NOT restrained by ties — restrained chimneys must be
        flagged differently in the feed (e.g. chimney_restrained = 'Y') → add guard in R01
  - [ ] H is measured to top of chimney pot or flue terminal (§2D1) — ensure feed measures correctly
  - [ ] W is least horizontal dimension at the highest roof intersection (§2D1, Diagram 20)
  - [ ] Two-flue chimneys: W is the full width of the combined chimney stack (Diagram 20)
  - [ ] _MAX_CYCLES recommended: 2 chimneys × 1 rule × 5 agents × 10 = 100 (well within default)
  - [ ] ⚠️ _CYCLE and _SUCCES are reset to 0 at the start of every loop() call — do not use
        them as cumulative counters across loop() calls. To accumulate a global total,
        write to a dedicated BOARD slot from within a rule.
        [ref: pitfalls.org §_CYCLE and _SUCCES — DISCOVERED 2026-07-24]
