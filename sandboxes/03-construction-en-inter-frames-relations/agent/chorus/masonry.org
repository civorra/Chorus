* Domain
  Verification of masonry unit compressive strength and wall tie specification.
  This agent handles sections 2C21 and Tables 6, 7 of Approved Document A:

  - Determines the compressive strength condition (A, B or C) from Diagram 9
    based on storey position (top / intermediate / base) and storey height
  - Verifies that the declared compressive strength of masonry units meets
    Table 6 requirements (brick and block, all material types)
  - Verifies normalised compressive strength for clay and calcium silicate
    blocks per Table 7 (Conditions A/B/C, Groups 1 and 2)
  - Sets ~besoin_foundation~ targeting slot for ADA::Agent::Foundation

  Pipeline position 3/4 — depends on ADA::Agent::Wall having set ~besoin_masonry~.

* Targeting Slots                                                        :SCOPE:
  /This agent processes external walls and parapet walls tagged by Agent::Wall./

** Chosen Strategy
   Strategy B — presence slot.
   Agent::Wall sets ~besoin_masonry~ = 'Y' on external walls and parapet walls
   after thickness verification. Agent::Masonry scopes on that presence slot.

   Chosen strategy : B
   Justification   : Direct presence-slot lookup; avoids re-filtering all Frames

* Ontology
  Core concepts from corpus §2C21, Diagram 9, Tables 6, 7:

  - *Masonry condition* → A / B / C — determined by storey position and storey height Hs
    (Diagram 9). Controls minimum strength requirements in Table 6.
  - *Brick* → masonry unit ≤ 337.5mm length AND ≤ 112.5mm height (Table 6 Note 3)
  - *Block* → masonry unit exceeding either brick limiting dimension, height ≥ 190mm
  - *Group 1* → ≤ 25% formed voids (≤ 20% for frogged bricks)
  - *Group 2* → 25%–55% formed voids
  - *Condition A* → single-storey top section, or upper section where Hs ≤ 2.7m
  - *Condition B* → intermediate sections and base where Hs ≤ 2.7m; all sections where Hs > 2.7m
  - *Condition C* → base section of multi-storey buildings with loaded bearing walls

* Rule Catalogue
** Rule: R01-masonry-condition
   Intent    : Determine the masonry condition (A, B or C) from Diagram 9 based on storey
               position, storey height Hs, and number of storeys.
   Priority  : 1

   FIND      :
   - ~w~ → attribut: ~besoin_masonry~

   EXCEPTION : ~defined $w->{masonry_condition}~
   EFFECT    :
   #+BEGIN_SRC perl
   use ADA::Agent::Masonry::Helpers qw(diagram9_condition);

   my $cond = diagram9_condition(
       $w->{storey_position}      // 'single',
       $w->{storey_height_m}      // 0,
       $w->{num_storeys_building} // 1,
       $w->{hf_m}                 // 0,
   );
   $w->set('masonry_condition', $cond);
   1
   #+END_SRC

   Notes: Parapet walls are always condition A (above roof, no structural load).
          diagram9_condition returns 'A', 'B', or 'C'.

** Rule: R02-masonry-strength
   Intent    : Verify declared compressive strength of masonry units meets Table 6 minimum
               for the determined condition (A, B or C). Set besoin_foundation.
   Priority  : 2

   FIND      :
   - ~w~ → attribut: ~besoin_masonry~

   EXCEPTION : ~defined $w->{masonry_ok}~
   CONDITION : ~defined $w->{masonry_condition}~
   EFFECT    :
   #+BEGIN_SRC perl
   use ADA::Agent::Masonry::Helpers qw(min_strength_table6);
   my @violations;

   my $cond    = $w->{masonry_condition}        // 'A';
   my $utype   = $w->{masonry_unit_type}        // 'brick';
   my $mat     = $w->{masonry_material}         // 'clay';
   my $grp     = $w->{masonry_group}            // 1;
   my $dec_str = $w->{declared_strength_nmm2}   // 0;

   my $min_str = min_strength_table6($cond, $utype, $mat, $grp);

   if (defined $min_str) {
       if ($dec_str < $min_str) {
           push @violations,
               "declared_strength ${dec_str}N/mm² < min ${min_str}N/mm² "
               . "(Table 6, cond $cond, $utype, $mat, Gr$grp)";
       }
       $w->set('masonry_strength_ok', ($dec_str >= $min_str) ? 'YES' : 'NO');
   } else {
       # manufactured_stone: any unit complying with BS EN 771-5 is acceptable
       $w->set('masonry_strength_ok', 'YES');
   }

   $w->set('masonry_violations', join('; ', @violations));
   $w->set('masonry_ok',         @violations ? 'NO' : 'YES');
   $w->set('besoin_foundation',  'Y')
       if ($w->{type_element} // '') eq 'external_wall';
   1
   #+END_SRC

   Notes: manufactured_stone (BS EN 771-5) → no numeric minimum → always 'YES'.
          besoin_foundation set only on external_wall (not parapet_wall).

** Rule: R03-normalised-strength-blocks
   Intent    : Verify normalised compressive strength of clay/CaSi blocks meets Table 7.
               Only applies to block units of clay or calcium_silicate material.
   Priority  : 3

   FIND      :
   - ~w~ → attribut: ~besoin_masonry~
           [filtre: ~'($_->{masonry_unit_type}//"") eq "block" && ($_->{masonry_material}//"") =~ /^(clay|calcium_silicate)$/'~]

   EXCEPTION : ~defined $w->{masonry_normalised_ok}~
   CONDITION : ~defined $w->{masonry_condition} && defined $w->{normalised_strength_nmm2}~
   EFFECT    :
   #+BEGIN_SRC perl
   use ADA::Agent::Masonry::Helpers qw(min_normalised_table7);

   my $cond     = $w->{masonry_condition}          // 'A';
   my $grp      = $w->{masonry_group}              // 1;
   my $norm_str = $w->{normalised_strength_nmm2}   // 0;

   my $min_norm = min_normalised_table7($cond, $grp);
   my @viol     = split /;\s*/, ($w->{masonry_violations} // '');

   if ($norm_str < $min_norm) {
       push @viol,
           "normalised_strength ${norm_str}N/mm² < min ${min_norm}N/mm² "
           . "(Table 7, cond $cond, Gr$grp)";
       $w->set('masonry_ok', 'NO');
   }

   $w->set('masonry_normalised_ok', ($norm_str >= $min_norm) ? 'YES' : 'NO');
   $w->set('masonry_violations',    join('; ', @viol));
   1
   #+END_SRC

   Notes: Table 7 applies only to clay and calcium silicate block units exceeding
          337.5mm length or 112.5mm height. Smaller blocks use brick thresholds (Table 7 Note 2).

** Rule: R04-mortar-specification
   Intent    : Verify mortar designation meets §2C22: designation (iii), strength class M4,
               or 1:1:5-6 CEM I/lime/sand mix by volume, or equivalent.
               Only fires when mortar_designation is provided in the JSON.
   Priority  : 4

   FIND      :
   - ~w~ → attribut: ~besoin_masonry~
           [filtre: ~'defined $_->{mortar_designation}'~]

   EXCEPTION : ~defined $w->{mortar_ok}~
   EFFECT    :
   #+BEGIN_SRC perl
   my @viol = split /;\s*/, ($w->{masonry_violations} // '');

   my $desig = $w->{mortar_designation} // '';

   # §2C22: accepted designations
   my $accepted = ($desig =~ /^(iii|M4|1:1:[56](-6)?|equivalent)$/i) ? 1 : 0;

   unless ($accepted) {
       push @viol,
           "mortar_designation '$desig' not one of: designation(iii), M4, 1:1:5-6, equivalent (§2C22)";
       $w->set('masonry_ok', 'NO');
   }

   $w->set('mortar_ok',          $accepted ? 'YES' : 'NO');
   $w->set('masonry_violations', join('; ', @viol));
   1
   #+END_SRC

   Notes: mortar_designation is optional — rule skips silently when slot absent.
          'equivalent' covers mortars of equivalent or greater strength and durability (§2C22b).

* Perl Helpers
** diagram9_condition
   Signature   : ~sub diagram9_condition($storey_position, $hs_m, $num_storeys, $hf_m) → 'A'|'B'|'C'~
   Description : Returns the masonry condition (A, B, or C) per Diagram 9 of the corpus.
                 Rules:
                 - Single storey: Condition A throughout (Hs ≤ 2.7m);
                   if Hs > 2.7m → Condition B throughout
                 - Two/Three storeys, top storey: Condition A (Hs ≤ 2.7m) or B (Hs > 2.7m)
                 - Two/Three storeys, intermediate: Condition B
                 - Two/Three storeys, base: Condition C
                 - Parapet wall: always Condition A
                 - Basement portion (hf_m > 1m): Condition B (Diagram 9 note)
   Called by   : R01-masonry-condition
   Exported    : yes — add to @EXPORT_OK
   Notes       : Diagram 9 Note 4 — this guidance applies only where roof is timber construction.

   #+BEGIN_SRC perl
   # Diagram 9 — Compressive strength conditions
   # Source corpus: Diagram 9 (p.26), §2C21
   #
   # Hs ≤ 2.7m → use key as shown; Hs > 2.7m → minimum Condition B or key, whichever greater
   # Key hierarchy: A < B < C
   #+END_SRC

** min_strength_table6
   Signature   : ~sub min_strength_table6($condition, $unit_type, $material, $group) → $nmm2 | undef~
   Description : Returns minimum declared compressive strength (N/mm²) from Table 6.
                 Returns undef for manufactured_stone (BS EN 771-5 — any complying unit acceptable).
   Called by   : R02-masonry-strength
   Exported    : yes — add to @EXPORT_OK

   #+BEGIN_SRC perl
   # Table 6 — Declared compressive strength of masonry units (N/mm²)
   # Source corpus: Table 6 (p.25)
   #
   # Structure: $TABLE6{$condition}{$unit_type}{$material}{$group}
   #
   # Condition A:
   #   brick: clay Gr1=6.0  Gr2=9.0  | CaSi Gr1=6.0  Gr2=9.0  | aggregate_concrete=6.0 | aac=N/A
   #   block: clay → Table 7         | CaSi → Table 7           | aggregate_concrete=2.9 | aac=2.9
   #
   # Condition B:
   #   brick: clay Gr1=9.0  Gr2=13.0 | CaSi Gr1=9.0  Gr2=13.0 | aggregate_concrete=9.0 | aac=N/A
   #   block: clay → Table 7         | CaSi → Table 7           | aggregate_concrete=7.3 | aac=7.3
   #
   # Condition C:
   #   brick: clay Gr1=18.0 Gr2=25.0 | CaSi Gr1=18.0 Gr2=25.0 | aggregate_concrete=18.0| aac=N/A
   #   block: clay → Table 7         | CaSi → Table 7           | aggregate_concrete=7.3 | aac=7.3
   #
   # manufactured_stone (BS EN 771-5): any complying unit → undef (no numeric minimum)
   #+END_SRC

** min_normalised_table7
   Signature   : ~sub min_normalised_table7($condition, $group) → $nmm2~
   Description : Returns minimum normalised compressive strength (N/mm²) from Table 7.
                 Applies to clay and calcium silicate block masonry units only.
                 Table 7 combines both standards: values are the same for clay (EN 771-1)
                 and CaSi (EN 771-2) blocks.
   Called by   : R03-normalised-strength-blocks
   Exported    : yes — add to @EXPORT_OK

   #+BEGIN_SRC perl
   # Table 7 — Normalised compressive strength (N/mm²)
   # Source corpus: Table 7 (p.27)
   #
   # Condition A: Group 1 = 5.0,  Group 2 = 8.0
   # Condition B: Group 1 = 7.5,  Group 2 = 11.0
   # Condition C: Group 1 = 15.0, Group 2 = 21.0
   #
   # Same values for clay (EN 771-1) and CaSi (EN 771-2) blocks per Table 7.
   my %TABLE7 = (
     A => { 1 => 5.0,  2 => 8.0  },
     B => { 1 => 7.5,  2 => 11.0 },
     C => { 1 => 15.0, 2 => 21.0 },
   );
   #+END_SRC

* Constraints & Pitfalls
  - [ ] R01 MUST fire before R02 — CONDITION in R02 checks ~defined masonry_condition~;
        if R01 is skipped (e.g. EXCEPTION failure) R02 returns early safely
  - [ ] ~masonry_normalised_ok~ only written for block Frames with clay/CaSi material
        AND when ~normalised_strength_nmm2~ is present in the JSON — absence is valid
        (normalised strength is optional input)
  - [ ] AAC (autoclaved aerated concrete) brick → no entry in Table 6 (marked '–') →
        min_strength_table6 returns undef for aac+brick → masonry_strength_ok = 'YES'
        (no applicable numeric constraint in Table 6)
  - [ ] aggregate_concrete block: Table 6 values are dry strengths (*) → caller must
        ensure declared_strength_nmm2 is the BS EN 772-1 dry value
  - [ ] Table 7 Note 2: applies only to blocks exceeding 337.5mm length OR 112.5mm height;
        smaller units use Table 6 brick thresholds — the feed must pre-classify correctly
  - [ ] besoin_foundation set only on external_wall (parapet_wall is above roof → no foundation check)
  - [ ] _MAX_CYCLES recommended: 15 wall Frames × 3 rules × 4 agents × 10 = 1800
