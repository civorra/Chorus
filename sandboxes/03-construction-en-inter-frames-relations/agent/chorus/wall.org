* Domain
  Verification of wall thickness, cavity construction and buttressing rules.
  This agent handles sections 2C6, 2C17 and Table 3 of Approved Document A:

  - Verifies minimum thickness of external/compartment/separating walls (Table 3)
  - Verifies solid wall thickness ≥ storey_height / 16 (§2C6)
  - Verifies cavity wall leaf minimum thickness (90mm each leaf, cavity 50–175mm)
  - Verifies parapet wall thickness rules (type A cavity / type B solid)
  - Verifies buttressing wall dimensions (length ≥ H/6, §2C17)
  - Verifies cavity ties specification (Table 5)
  - Sets ~besoin_masonry~ targeting slot for ADA::Agent::Masonry

  Pipeline position 2/4 — depends on ADA::Agent::Geometry having set ~besoin_wall~.

* Targeting Slots                                                        :SCOPE:
  /This agent processes Frames tagged by ADA::Agent::Geometry./

** Chosen Strategy
   Strategy B — presence slot.
   Agent::Geometry sets ~besoin_wall~ = 'Y' on every building and wall Frame
   after geometric verification. Agent::Wall scopes on that slot only.

   Chosen strategy : B
   Justification   : Wall Frames outnumber building Frames (one project may have
                     many walls); Strategy B avoids scanning all Frames with a
                     filtre on type_element — direct presence-slot lookup is O(1).

* Ontology
  Core concepts from corpus §2C6, §2C17, §2C18, §2C19, Table 3, Table 5:

  - *External wall* → Frame ~external_wall~ — solid or cavity construction
  - *Internal wall* → Frame ~internal_wall~ — loadbearing or partition
  - *Parapet wall* → Frame ~parapet_wall~ — type A (cavity) or B (solid), above roof line
  - *Buttressing wall* → Frame ~buttressing_wall~ — provides lateral support, §2C17
  - *Pier* → integral thickened section of a wall, lateral support function (§2.3 Definitions)
  - *Cavity tie* → metal tie connecting two leaves, specified in Table 5
  - *Cavity width* → horizontal distance between two leaves (§2.3 Definitions)

** Rule: R01-external-wall-thickness

               and solid wall 1/16 storey height rule (§2C6). If wall_construction_material
               is 'uncoursed_stone' apply §2C7 multiplier 1.33 to the §2C6 minimum.
               Set besoin_masonry.

   my $l    = $w->{length_m}  // 0;
