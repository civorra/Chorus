* Perl Helpers
  Module `lib/WidgetCompliance/Helpers.pm` — partagé par `agent-load` et `agent-algo`.
  - `algo_status($algorithm)` → `'approved'|'deprecated'|undef` — source ARF-2.1 §3.2.
  - `min_key_length($algorithm)` → integer|undef — source ARF-2.1 §3.2 Table 3.2-1.
  - `key_crack_benchmark($algorithm)` → `{ key_length, cost, year }`|undef —
    justification empirique uniquement, ne détermine jamais `algo_ok`. Source
    CIR-1.0 Annex C (Table C.1), classée `HELPER-SOURCE` par
    `chorus-corpus-scoping` Phase 2 Step 0b (exécution réelle, 2026-09-20 —
    voir `TEST-PLAN-helper-source.md`). Appelé par `R02-algo-keylength.yml`
    (branche NON) pour enrichir `motif_algo`.

* Constraints & Pitfalls
  - §4.1 ARF (implementation guidance) intentionally excluded — no_auto_rules per
    CORPUS-DIRECTIVES. Contains no verifiable threshold. Retry confirmed 0 codifiable
    sub-clauses: "should select", "appropriate", "considering" — all prose guidance.
  - R01 fires on deprecated algos (sets algo_ok=NON immediately).
    R02 fires only on approved algos with insufficient key length.
    If algorithm is unknown (not in ARF §3.2): R01 sets NON with "unknown algorithm" motif.
  - key_length_bits absent from project JSON: R02 CONDITION fails → no verdict on key length.
    Document in import instructions: key_length_bits is mandatory for algo_ok=OUI.
