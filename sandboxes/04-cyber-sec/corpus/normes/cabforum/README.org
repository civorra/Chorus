* Règles directement encodables

** Durée de validité TLS (Baseline Requirements §6.3.2)

- Certificats TLS publics : =398 jours maximum= (depuis sept. 2020)
- Certificats Code Signing : 39 mois maximum

→ Règle YAML : comparer =validity_days= au seuil selon le profil

** keyUsage TLS (Baseline Requirements §7.1.2)

Selon l'usage :
- RSA end-entity : =digitalSignature= requis
- RSA CA : =keyCertSign= + =cRLSign= requis
- ECDSA end-entity : =digitalSignature= requis

** extendedKeyUsage TLS (Baseline Requirements §7.1.2.3)

- id-kp-serverAuth (1.3.6.1.5.5.7.3.1) : requis pour certificats serveur TLS
- id-kp-clientAuth (1.3.6.1.5.5.7.3.2) : optionnel

** Subject Alternative Name (Baseline Requirements §7.1.4)

- SAN obligatoire depuis 2012 (CN seul insuffisant)
- Noms wildcard : règles de format strictes

** Algorithmes interdits (Baseline Requirements §7.1.3)

- SHA-1 : interdit pour les nouveaux certificats TLS publics
- RSA < 2048 bits : interdit
- MD5 : interdit
