* Règles directement encodables

** ETSI EN 319 412-5 — QC Statements (OIDs qualifiés)

Extensions spécifiques eIDAS dans le certificat :
- =id-etsi-qcs-QcCompliance= : certificat qualifié conforme eIDAS
- =id-etsi-qcs-QcSSCD= : clé dans dispositif sécurisé (QSCD)
- =id-etsi-qcs-QcType= : type (esign, eseal, web)
- =id-etsi-qcs-QcPDS= : URL du Policy Disclosure Statement

→ Règles YAML : vérifier présence/absence des OIDs selon le profil déclaré

** ETSI TS 119 312 — Algorithmes

Tableau de recommandations par période :
- RSA : longueur minimale selon année (4096 bits recommandé post-2024)
- ECDSA P-256 : acceptable jusqu'en 2030+
- SHA-256 minimum requis

** ETSI EN 319 411-1 — Niveaux de politique

- LCP (Lightweight Certificate Policy)
- NCP (Normalized Certificate Policy)
- NCP+ (NCP with SSCD requirement)
