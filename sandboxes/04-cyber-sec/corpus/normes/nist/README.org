* Règles directement encodables

** SP 800-57 — Durées de vie des clés par type

| Type de clé          | Usage recommandé | Durée de vie max (usage cryptographique) |
|----------------------+------------------+------------------------------------------|
| Clé privée signature | Émission seule   | 1-3 ans selon SP 800-57 §5.3.6          |
| Clé publique vérif.  | Vérification     | Peut dépasser la clé privée             |
| Clé de chiffrement   | Symétrique       | 2 ans max pour AES-128                  |
| Clé AC racine        | Émission CA      | 10-20 ans                               |

→ Règles YAML : =private_key_age_days= selon =key_type= et =algorithm=

** SP 800-131A — Algorithmes dépréciés (calendrier)

- SHA-1 pour signatures : disallowed depuis 2014
- RSA 1024 bits : disallowed depuis 2014
- 2TDEA (Triple-DES 2 clés) : disallowed depuis 2024
- DSA 1024/160 : disallowed depuis 2014

→ Règles YAML : détecter l'usage d'algorithmes dépréciés dans la configuration

** FIPS 140-3 — Niveaux de sécurité HSM

- Niveau 1 : exigences de base
- Niveau 2 : preuves de sabotage
- Niveau 3 : résistance au sabotage + réponse active
- Niveau 4 : protection complète enveloppe

→ Règle YAML : =hsm_fips_level= >= seuil requis selon le profil de certification
