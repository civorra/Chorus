* Règles encodables (couche configuration)

Un produit CMS peut être certifié CC EAL4+. Les éléments vérifiables en pré-déploiement :

- =fcs_cop.1= : opérations cryptographiques conformes aux algorithmes déclarés dans la ST
- =fcs_ckm.1= : génération de clés selon les standards (FIPS 186)
- =fcs_ckm.4= : destruction des clés cryptographiques
- =fia_uau.2= : authentification avant tout accès

→ Règles YAML : vérifier que la configuration CMS déclare les bons algorithmes
  et que les modules HSM sont certifiés au bon niveau EAL

* Protection Profiles cartes à puce

Les PP disponibles sur le portail CC pour les cartes à puce définissent les exigences
de sécurité de la plateforme sous-jacente au CMS. Pertinent pour la validation de la
chaîne de confiance complète (IC → OS → Application → PKI).
