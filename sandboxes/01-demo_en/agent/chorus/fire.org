* Domain
  Verifies fire safety compliance: required fire resistance period by occupancy
  type (§5.1), reaction to fire class and surface mass of internal lining (§5.2),
  and plasterboard thickness by required REI period (§5.3). Operates on all
  structural and lining elements that carry the =needs_fire= targeting slot.

* Targeting slots
** Strategy
   Strategy B — presence slot =needs_fire=.
   Set by Feed.pm initial load on all elements (fire rules apply universally
   per §6.1: both collective=0 and collective=1 require fire_ok='YES').

** Table
   | Slot       | Set by       | Consumed by                   |
   |------------+--------------+-------------------------------|
   | needs_fire | initial feed | This agent (TimberFrame::Agent::Fire) |

** Pre-population contract
   Feed.pm sets =needs_fire= on all elements. The =collective= slot is a
   project-level attribute (not per element) — set on each Frame by Feed.pm
   from the project JSON top-level field.

* Pipeline I/O
** Incoming slots
   - =type_element= — element type
   - =needs_fire= — targeting slot
   - =collective= — 0 (non-collective) or 1 (multi-occupancy)
   - =rei_period= — achieved fire resistance period (minutes: 30 or 60)
   - =reaction_class= — Euroclass (A1, A2, B, C, D, E, F)
   - =surface_mass_kg_m2= — surface mass of internal lining (kg/m²)
   - =plasterboard_thickness_mm= — plasterboard thickness (mm)

** Outgoing slots
   - =fire_ok= — 'YES' or 'NO'
   - =fire_rejection= — human-readable reason if fire_ok='NO'

* Perl Helpers

** min_rei_required
   # Source corpus: §5.1 — Building Regs Part B / BS EN 13501-2 — Fire resistance by occupancy
   # Signature: min_rei_required($collective) → int (minutes)
   # Called by: R01-rei-period.yml (ACTION)
   Returns minimum required REI period:
     collective = 0 → 30 minutes
     collective = 1 → 60 minutes

** reaction_class_rank
   # Source corpus: §5.2 — BS EN 13501-1 — Euroclass ranking (A1 best)
   # Signature: reaction_class_rank($class) → int (rank, higher = worse) or 99 if unknown
   # Called by: R02-lining-class.yml (ACTION)
   Returns numeric rank for comparison:
     A1 → 1, A2 → 2, B → 3, C → 4, D → 5, E → 6, F → 7
     unknown → 99 (worst)

** min_pb_thickness
   # Source corpus: §5.3 — Building Regs Part B §B3 — Plasterboard thickness by REI
   # Signature: min_pb_thickness($rei_period) → float (mm) or undef if not applicable
   # Called by: R03-pb-thickness.yml (ACTION)
   Returns minimum plasterboard thickness:
     REI 30 (non-collective) → 12.5 mm
     REI 60 (collective)     → 25 mm
     other → undef (no specific requirement — accept)

* Constraints & Pitfalls
  - insulation and vapour_control_layer: skip fire checks silently (no rei or lining check).
  - R02 lining class applies to internal lining elements; guard on type in filtre.
  - reaction_class comparison: A1 and A2 are compliant, B and below are not.
  - _MAX_CYCLES recommended: 50 × 3 × 5 × 10 = 7 500 (engine default sufficient for demo).
