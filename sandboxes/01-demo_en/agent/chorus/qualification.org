* Domain
  Verifies timber material compliance: strength class (§2.1), moisture content (§2.2),
  and allowable deflection (§2.3). Produces per-element qualification verdict and sets
  the targeting slot for downstream agents.

* Targeting slots
** Strategy
   Strategy B — presence slot.
   All elements from the project JSON carry the targeting slot =needs_compliance=
   set by the initial feed. Qualification agent is the entry point.

** Table
   | Slot             | Set by       | Consumed by                       |
   |------------------+--------------+-----------------------------------|
   | needs_compliance | initial feed | TimberFrame::Agent::Compliance (pos.5) |
   | needs_geometry   | R04 (this agent) | TimberFrame::Agent::Geometry (pos.2) |
   | needs_thermal    | Feed (initial) | TimberFrame::Agent::Thermal (pos.3) |
   | needs_fire       | Feed (initial) | TimberFrame::Agent::Fire (pos.4)   |

** Pre-population contract
   Feed.pm sets =needs_compliance= on all elements.
   This agent also sets =needs_geometry= on structural elements.

* Pipeline I/O
** Incoming slots
   - =type_element= — element type (from project JSON)
   - =strength_class= — BS EN 338 class (C14…C40)
   - =moisture_pct= — moisture content at installation (%)
   - =deflection_mm= — measured instantaneous deflection (mm)
   - =span_mm= — span length (mm) — required for deflection check

** Outgoing slots
   - =qualified= — 'YES' or 'NO'
   - =rejection_reason= — human-readable reason if qualified='NO'
   - =needs_geometry= — set on structural elements to trigger geometry agent

* Perl Helpers

** min_strength_class_required
   # Source corpus: §2.1 — BS EN 338 — Minimum strength class by element type
   # Signature: min_strength_class_required($type_element) → string (class) or undef
   # Called by: R01-strength-class.yml (ACTION)
   Returns the minimum BS EN 338 class required for a given element type.
   Returns undef for elements with no strength class requirement (insulation, VCL).

   Values:
     load_bearing_stud  => C24
     sole_plate         => C24
     top_plate          => C24
     joist              => C24
     rafter             => C18
     non_load_bearing_stud => C16
     insulation         => undef (no requirement)
     vapour_control_layer => undef (no requirement)

** class_rank
   # Source corpus: §2.1 — BS EN 338 — Ascending strength classification
   # Signature: class_rank($class) → integer (rank) or 0 if unknown
   # Called by: R01-strength-class.yml (ACTION) — comparison helper
   Returns numeric rank for class comparison: C14=1, C16=2, C18=3, C24=4, C30=5, C35=6, C40=7.

* Constraints & Pitfalls
  - Elements without strength_class (insulation, VCL) must pass R01 without rejection.
  - deflection check requires both deflection_mm and span_mm — skip silently if absent.
  - _MAX_CYCLES recommended: 50 elements × 4 rules × 5 agents × 10 = 10 000 (engine default sufficient for demo)
