* Domain
  This agent handles Chapter 4 (medication management and drug stewardship) and
  Chapter 5 (optimal models of care) of the KDIGO 2024 Clinical Practice Guideline.

  Responsibilities:
  - Contrast media safety checks (§4.4.1.2, §4.4.2.1)
  - KRT (kidney replacement therapy) planning trigger when eGFR <15–20 or 2-year KFR >40% (§5.4.3)
  - Atrial fibrillation anticoagulation check: NOACs preferred for CKD G1–G4 (§3.16.1)
  - Metabolic acidosis treatment check when bicarbonate <18 mmol/l (§3.10.1)
  - Terminal rule: =solved()= once all checks complete

  Functional dependencies: requires =besoin_care= from Treatment agent (pos. 3).

* Rule Catalogue
** Rule: R01-contrast-media
   Intent    : Check gadolinium contrast safety for G4–G5 patients (§4.4.2.1).
   CORPUS    : §4.4.2 — KDIGO 2024 — Gadolinium-containing contrast media (PP 4.4.2.1)
   EXCEPTION : =defined $p->{gadolinium_safe}=

** Rule: R02-krt-planning
   Intent    : Trigger KRT planning flag when eGFR <15–20 or 2-year KFR >40% (§5.4.3).
   CORPUS    : §5.4.3 — KDIGO 2024 — PP 5.4.3 — Timing KRT preparation
   EXCEPTION : =defined $p->{krt_planning_flag}=

** Rule: R04-drug-dosing-flag
   Intent    : Flag patients requiring high-accuracy GFR measurement for drug dosing
               when they are on narrow therapeutic index (TI) drugs (§4.2.3).
               PP 4.2.3: use cystatin C-based or measured GFR for narrow TI drugs
               or when eGFRcr may be unreliable.
   CORPUS    : §4.2 — KDIGO 2024 — Dose adjustments by level of GFR (PP 4.2.1–4.2.5)
   FIND      :
   - =p= → attribut: =besoin_care= (Strategy B)
   EXCEPTION : =defined $p->{drug_dosing_review_flag}=
   ACTION    :
   #+BEGIN_SRC perl
   my $g             = $p->{ckd_g_category} // '';
   my $narrow_ti     = $p->get('takes_narrow_ti_drug') // 0;
   # PP 4.2.3: narrow TI drugs + G3-G5 → cystatin C or mGFR for higher accuracy
   if ($narrow_ti && $g =~ /^G(3|4|5)/) {
       $p->set('drug_dosing_review_flag', 'NARROW_TI');   # high-accuracy GFR needed
   } elsif (!$g) {
       $p->set('drug_dosing_review_flag', 'NA');
   } else {
       $p->set('drug_dosing_review_flag', 'ROUTINE');     # standard eGFRcr sufficient
   }
   1
   #+END_SRC

** Rule: R03-termination
   Intent    : Once all care model checks are complete, compute overall compliance
               and call =solved()= to terminate the pipeline.
   CORPUS    : §5 — KDIGO 2024 — Pipeline termination
   EXCEPTION : =defined $p->{overall_compliance}=

* Constraints & Pitfalls
  _MAX_CYCLES recommended: N_patients × 3_rules × 1_agent × 10

  - [ ] R03 termination: =overall_compliance= is set as a simple label based on presence of NON slots
  - [ ] Gadolinium check applies only when =needs_gadolinium= is present and is truthy; absent → NA
  - [ ] KRT planning: eGFR <15 is a soft threshold — actual dialysis initiation depends on symptoms (§5.4.2)
  - [ ] §3.16.1 NOAC rule: applies to CKD G1–G4 only; G5 excluded (use caution at G4–G5, PP 3.16.2)
