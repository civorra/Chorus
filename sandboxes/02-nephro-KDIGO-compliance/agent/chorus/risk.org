* Domain
  This agent performs risk assessment and monitoring guidance for CKD patients,
  based on Chapter 2 of the KDIGO 2024 Clinical Practice Guideline.

  Responsibilities:
  - Determine monitoring frequency (annual lab visits per year) from G+A stage
  - Assign the referral tier from kidney failure risk thresholds (§2.2)
  - Flag significant eGFR change (>20%) or ACR doubling when historical data available
  - Set the targeting slot =besoin_treatment= for the Treatment agent

  Functional dependencies: requires =ckd_g_category=, =ckd_a_category= and =besoin_risk=
  set by Agent Staging (pos. 1).

* Targeting Slots                                                        :SCOPE:

** Chosen Strategy
   Strategy B — presence slot:
   =besoin_risk= is set exclusively by Agent Staging on patients that have been staged.
   This avoids re-scanning all patients and guarantees the agent only sees
   properly staged patients.

   Chosen strategy : B
   Justification   : presence slot =besoin_risk= set by upstream agent; volume may
                     grow (population screening context) so Strategy B is more scalable.

* Rule Catalogue
** Rule: R01-monitoring-frequency
   Intent    : Assign recommended monitoring frequency (visits/year) based on G+A CKD stage.
   CORPUS    : §2.1 — KDIGO 2024 — Monitoring for progression (Practice Points 2.1.1–2.1.2)
   FIND      :
   - =p= → attribut: =besoin_risk= (Strategy B — no filter)
   EXCEPTION : =defined $p->{monitoring_per_year}=
   ACTION    :
   #+BEGIN_SRC perl
   my $g = $p->{ckd_g_category} // '';
   my $a = $p->{ckd_a_category} // '';
   return 0 unless $g && $a;
   my $freq = monitoring_frequency_per_year($g, $a);
   $p->set('monitoring_per_year', $freq);
   1
   #+END_SRC

** Rule: R02-referral-tier
   Intent    : Assign the referral tier based on GFR category and kidney failure risk thresholds.
   CORPUS    : §2.2.1 + PP 2.2.1–2.2.3 — KDIGO 2024 — Risk prediction and referral thresholds
   FIND      :
   - =p= → attribut: =besoin_risk= (Strategy B — no filter)
   EXCEPTION : =defined $p->{referral_tier}=
   ACTION    :
   #+BEGIN_SRC perl
   my $g        = $p->{ckd_g_category} // '';
   my $kfr_2y   = $p->get('kidney_failure_risk_2y_pct');
   my $kfr_5y   = $p->get('kidney_failure_risk_5y_pct');
   my $tier = referral_tier_from_risk($g, $kfr_2y, $kfr_5y);
   $p->set('referral_tier', $tier);
   1
   #+END_SRC

** Rule: R02b-egfr-change-check
   Intent    : Flag significant eGFR change (>20%) when historical data is available (§2.1.3).
   CORPUS    : §2.1.3 — KDIGO 2024 — Practice Point 2.1.3
   FIND      :
   - =p= → attribut: =besoin_risk= (Strategy B)
   CONDITION : =defined $p->{prev_egfr_ml_min} && defined $p->{egfr_ml_min}=
   EXCEPTION : =defined $p->{egfr_change_flag}=
   ACTION    :
   #+BEGIN_SRC perl
   my $prev = $p->{prev_egfr_ml_min};
   my $curr = $p->{egfr_ml_min};
   return 0 unless $prev > 0;   # avoid division by zero
   my $change_pct = abs($curr - $prev) / $prev * 100;
   if ($change_pct > 20) {
       $p->set('egfr_change_flag', 'significant');
   } else {
       $p->set('egfr_change_flag', 'stable');
   }
   1
   #+END_SRC

** Rule: R03-set-besoin-treatment
   Intent    : Once risk assessment is complete, activate the Treatment agent.
   CORPUS    : §2 — KDIGO 2024 — Pipeline continuation
   FIND      :
   - =p= → attribut: =besoin_risk= (Strategy B)
   CONDITION : =defined $p->{monitoring_per_year} && defined $p->{referral_tier}=
   EXCEPTION : =defined $p->{besoin_treatment}=
   ACTION    :
   #+BEGIN_SRC perl
   # Set targeting slot for Agent Treatment (pos. 3)
   $p->set('besoin_treatment', 1);
   1
   #+END_SRC

* Perl Helpers
** monitoring_frequency_per_year
   Signature   : =sub monitoring_frequency_per_year($g_category, $a_category) → $int=
   Description : Returns the recommended number of monitoring visits per year based
                 on the GFR category and albuminuria category, per KDIGO 2024 §2.1 heat-map.
   Called by   : R01-monitoring-frequency
   Exported    : yes
   Notes       : The KDIGO monitoring frequency table (§2.1):
                 G1/G2 A1 → 1/year; G1/G2 A2 → 1/year; G1/G2 A3 → 2/year
                 G3a A1 → 1/year; G3a A2 → 1/year; G3a A3 → 2/year
                 G3b A1 → 2/year; G3b A2 → 2/year; G3b A3 → 3/year
                 G4 A1 → 3/year; G4 A2 → 3/year; G4 A3 → 4/year
                 G5 → 4+/year (specialist care, not captured here → returns 4)

** referral_tier_from_risk
   Signature   : =sub referral_tier_from_risk($g, $kfr_2y, $kfr_5y) → $tier_str=
   Description : Determines referral tier per §2.2.1 PP 2.2.1–2.2.3 and §5.1:
                 "krt_preparation"  — 2-year KFR >40%
                 "multidisciplinary" — 2-year KFR >10%
                 "nephrology"        — 5-year KFR 3–5% OR G4/G5
                 "primary_care"      — otherwise
   Called by   : R02-referral-tier
   Exported    : yes

* Constraints & Pitfalls
  _MAX_CYCLES recommended: N_patients × 4_rules × 1_agent × 10

  - [ ] =monitoring_frequency_per_year= table covers adults; pediatric corrections needed with =is_child= slot
  - [ ] R02 referral tier falls back to =primary_care= when no KFR score is available — acceptable for initial assessment
  - [ ] R02b (eGFR change) fires only when =prev_egfr_ml_min= is present; no slot set = no flag (not an error)
  - [ ] R03 depends on R01 AND R02 having fired — ensured by CONDITION guard (both slots must be defined)
