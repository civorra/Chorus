* Domain
  This agent checks compliance with treatment recommendations for CKD patients
  defined in Chapter 3 of the KDIGO 2024 Clinical Practice Guideline.

  Responsibilities:
  - RASi indication and compliance (§3.6)
  - SGLT2 inhibitor indication and compliance (§3.7)
  - Nonsteroidal MRA indication and compliance (§3.8)
  - GLP-1 RA indication and compliance (§3.9)
  - Statin indication and compliance (§3.15.1)
  - Blood pressure target compliance (§3.4.1: SBP <120 mmHg)
  - GLP-1 RA for T2D not at target (§3.9.1)
  - Physical activity compliance (§3.2.2.1: ≥150 min/week)
  - Protein intake compliance (§3.3.1.1: 0.8 g/kg/d for G3–G5)
  - Sodium intake compliance (§3.3.2.1: <2 g/day)
  - Metabolic acidosis treatment (§3.10.1: bicarbonate <18 mmol/l)
  - Set targeting slot =besoin_care= for the Care agent

  Functional dependencies: requires =besoin_treatment=, =ckd_g_category=,
  =ckd_a_category= from earlier agents.

** Rule: R10-hyperuricemia
   Intent    : Determine uric acid-lowering therapy indication per §3.14.
               Rec 3.14.1 (1C): symptomatic hyperuricemia/gout → offer treatment.
               Rec 3.14.2 (2D): asymptomatic hyperuricemia → do NOT lower to delay CKD.
   CORPUS    : §3.14 — KDIGO 2024 — Hyperuricemia (Rec. 3.14.1, 3.14.2)
   FIND      :
   - =p= → attribut: =besoin_treatment= (Strategy B)
   EXCEPTION : =defined $p->{uric_acid_lowering_indicated}=
   ACTION    :
   #+BEGIN_SRC perl
   my $symptomatic = $p->get('has_symptomatic_hyperuricemia') // 0;
   if ($symptomatic) {
       $p->set('uric_acid_lowering_indicated', 'yes');   # Rec 3.14.1 (1C)
       my $on_ual = $p->get('is_on_uric_acid_lowering');
       if (!defined $on_ual) {
           $p->set('uric_acid_lowering_compliant', 'NA');
       } elsif ($on_ual) {
           $p->set('uric_acid_lowering_compliant', 'OUI');
       } else {
           $p->set('uric_acid_lowering_compliant', 'NON');  # indicated but not prescribed
       }
   } else {
       $p->set('uric_acid_lowering_indicated', 'no');    # Rec 3.14.2 or not applicable
       $p->set('uric_acid_lowering_compliant', 'NA');
   }
   1
   #+END_SRC

** Rule: R11-antiplatelet
   Intent    : Check low-dose aspirin indication for secondary cardiovascular prevention (§3.15.2.1).
               Rec 3.15.2.1 (1C): established ischemic CVD → aspirin for secondary prevention.
   CORPUS    : §3.15.2 — KDIGO 2024 — Antiplatelet therapy (Rec. 3.15.2.1 1C)
   FIND      :
   - =p= → attribut: =besoin_treatment= (Strategy B)
   EXCEPTION : =defined $p->{antiplatelet_indicated}=
   ACTION    :
   #+BEGIN_SRC perl
   my $has_ascvd = $p->get('has_established_ascvd') // 0;
   if ($has_ascvd) {
       $p->set('antiplatelet_indicated', 'yes');   # Rec 3.15.2.1 (1C) secondary prevention
       my $on_asp = $p->get('is_on_aspirin');
       if (!defined $on_asp) {
           $p->set('antiplatelet_compliant', 'NA');
       } elsif ($on_asp) {
           $p->set('antiplatelet_compliant', 'OUI');
       } else {
           $p->set('antiplatelet_compliant', 'NON');  # secondary prevention aspirin missing
       }
   } else {
       $p->set('antiplatelet_indicated', 'no');
       $p->set('antiplatelet_compliant', 'NA');
   }
   1

** Rule: R12-hyperkalemia-diet
   Intent    : Flag dietary potassium restriction advice for G3-G5 patients with elevated K+
               per §3.11.5.2 (PP 3.11.5.2).
               K+ ≥ 5.0 mEq/L in CKD G3–G5 → recommend limiting high-potassium foods.
   CORPUS    : §3.11.5 — KDIGO 2024 — Hyperkalemia dietary considerations (PP 3.11.5.2)
   FIND      :
   - =p= → attribut: =besoin_treatment= (Strategy B)
   EXCEPTION : =defined $p->{hyperkalemia_dietary_flag}=
   ACTION    :
   #+BEGIN_SRC perl
   my $g = $p->{ckd_g_category} // '';
   my $k = $p->get('serum_potassium_meq_l');
   # PP 3.11.5.2: applies to G3–G5 patients
   if ($g =~ /^G(3|4|5)/ && defined $k && $k >= 5.0) {
       $p->set('hyperkalemia_dietary_flag', 'ADVISE');  # limit high-K foods (PP 3.11.5.2)
   } elsif (!$g) {
       $p->set('hyperkalemia_dietary_flag', 'NA');       # no staging data
   } else {
       $p->set('hyperkalemia_dietary_flag', 'OK');       # G1-G2 or K+ normal/absent
   }
   1
   #+END_SRC

* Perl Helpers
** rasi_indicated
   Signature   : =sub rasi_indicated($g, $a, $has_diabetes) → "yes"|"no"=
   Description : Returns "yes" if RASi is indicated per §3.6.1–3.6.3.
                 A3 without diabetes (G1–G4) → Rec. 3.6.1 (1B) → "yes"
                 A2 without diabetes (G1–G4) → Rec. 3.6.2 (2C) → "yes"
                 A2 or A3 with diabetes (G1–G4) → Rec. 3.6.3 (1B) → "yes"
                 G5 → exclude (kidney failure, not covered)
                 Otherwise → "no"
   Called by   : R01-rasi-indication
   Exported    : yes

* Constraints & Pitfalls
  _MAX_CYCLES recommended: N_patients × 12_rules × 1_agent × 10

  - [ ] All rules except R09 use the same FIND (=besoin_treatment=) — alphabetical load order
        ensures R01 fires before R09; no explicit dependency ordering needed
  - [ ] R09 CONDITION updated: waits for =uric_acid_lowering_indicated=, =antiplatelet_indicated=,
        =hyperkalemia_dietary_flag= in addition to the original slots — ensures R10-R12 fire first
  - [ ] When =is_on_rasi= is undef (not in JSON), rasi_compliant is set to "NA" (data absent)
  - [ ] G5 patients: RASi may be reduced/stopped at eGFR<15 (PP 3.6.5) — R01 sets "NA" for G5
  - [ ] SGLT2i: once started, may continue even if eGFR drops below 20 (PP 3.7.1) — R02 checks
        current initiation indication only, not continuation
  - [ ] MRA: §3.8 specifies nonsteroidal MRA only; steroidal MRA (spironolactone) not covered here
  - [ ] Statin rule: 10-year CVD risk is optional — without it, §3.15.1.3 check skipped for 18-49y
  - [ ] BP rule: only applicable to adults with high BP — if =systolic_bp_mmhg= absent → "NA"
  - [ ] Lifestyle rules: if optional slots absent → result = "NA" (no data), not NON
  - [ ] R10 hyperuricemia: =has_symptomatic_hyperuricemia= absent → no treatment indicated (Rec 3.14.2)
        Do not flag asymptomatic hyperuricemia — guideline explicitly recommends AGAINST treatment
  - [ ] R11 antiplatelet: =has_established_ascvd= absent → antiplatelet_indicated = "no" (no data)
        Primary prevention aspirin is NOT covered — §3.15.2.1 is secondary prevention only
  - [ ] R12 hyperkalemia: fires for ALL patients; G1-G2 or missing K+ → "OK"; G3-G5 + K+≥5.0 → "ADVISE"
        PP 3.11.5.2 is a Practice Point (no GRADE) — advisory flag, not a hard compliance breach
