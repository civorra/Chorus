* Domain
  This agent classifies patients according to the CKD staging system defined in the
  KDIGO 2024 Clinical Practice Guideline (Chapter 1).

  Responsibilities:
  - Assign the GFR category (G1–G5) from eGFR in ml/min per 1.73 m²
  - Assign the albuminuria category (A1–A3) from urine ACR in mg/g
  - Set the combined CKD stage (e.g., "G3aA2") for downstream agents
  - Set the targeting slot =besoin_risk= to activate the Risk agent

  Functional dependencies: none (first agent in pipeline — acts on raw patient data).

* Rule Catalogue
** Rule: R01-assign-g-category
   Intent    : Assign the KDIGO GFR category (G1–G5b) based on =egfr_ml_min=.
   CORPUS    : §1.1.2 — KDIGO 2024 — Methods for staging of CKD (GFR categories)
   FIND      :
   - =p= → attribut: =type_element=, filtre: ='$_->{type_element} eq "patient"'=
   EXCEPTION : =defined $p->{ckd_g_category}=
   ACTION    :
   #+BEGIN_SRC perl
   my $egfr = $p->get('egfr_ml_min');
   return 0 unless defined $egfr;
   my $cat = egfr_to_g_category($egfr);
   $p->set('ckd_g_category', $cat);
   1
   #+END_SRC

** Rule: R02-assign-a-category
   Intent    : Assign the KDIGO albuminuria category (A1–A3) based on =acr_mg_g=.
   CORPUS    : §1.3 — KDIGO 2024 — Evaluation of albuminuria (A categories)
   FIND      :
   - =p= → attribut: =type_element=, filtre: ='$_->{type_element} eq "patient"'=
   EXCEPTION : =defined $p->{ckd_a_category}=
   ACTION    :
   #+BEGIN_SRC perl
   my $acr = $p->get('acr_mg_g');
   return 0 unless defined $acr;
   my $cat = acr_to_a_category($acr);
   $p->set('ckd_a_category', $cat);
   1
   #+END_SRC

** Rule: R03-set-besoin-risk
   Intent    : Once G and A categories are assigned, set =besoin_risk= to activate
               the Risk agent. Also compose the combined CKD stage string.
   CORPUS    : §1.1.2 — KDIGO 2024 — CGA staging system
   FIND      :
   - =p= → attribut: =type_element=, filtre: ='$_->{type_element} eq "patient"'=
   CONDITION : =defined $p->{ckd_g_category} && defined $p->{ckd_a_category}=
   EXCEPTION : =defined $p->{besoin_risk}=
   ACTION    :
   #+BEGIN_SRC perl
   my $stage = $p->{ckd_g_category} . $p->{ckd_a_category};
   $p->set('ckd_stage', $stage);
   $p->set('besoin_risk', 1);
   1
   #+END_SRC

** Rule: R04-chronicity
   Intent    : Check chronicity of CKD by verifying that =ckd_duration_months= ≥ 3 months (§1.1.3).
               Sets =chronicity_confirmed= based on available data.
               Informational — does not block pipeline progression.
   CORPUS    : §1.1.3 — KDIGO 2024 — Evaluation of chronicity (PP 1.1.3.1, PP 1.1.3.2)
   FIND      :
   - =p= → attribut: =type_element=, filtre: ='$_->{type_element} eq "patient"'=
   EXCEPTION : =defined $p->{chronicity_confirmed}=
   ACTION    :
   #+BEGIN_SRC perl
   my $dur = $p->get('ckd_duration_months');
   if (!defined $dur) {
       $p->set('chronicity_confirmed', 'unknown');     # no duration data
   } elsif ($dur >= 3) {
       $p->set('chronicity_confirmed', 'confirmed');   # PP 1.1.3.1: ≥ 3 months
   } else {
       $p->set('chronicity_confirmed', 'unconfirmed'); # PP 1.1.3.2: may be AKI/AKD
   }
   1
   #+END_SRC

* Perl Helpers
** egfr_to_g_category
   Signature   : =sub egfr_to_g_category($egfr_ml_min) → $category_str=
   Description : Maps eGFR value (ml/min per 1.73 m²) to KDIGO GFR category G1–G5.
   Called by   : R01-assign-g-category
   Exported    : yes
   Notes       : G3 is split into G3a (45–59) and G3b (30–44).
                 Thresholds: ≥90=G1, 60–89=G2, 45–59=G3a, 30–44=G3b, 15–29=G4, <15=G5.

** acr_to_a_category
   Signature   : =sub acr_to_a_category($acr_mg_g) → $category_str=
   Description : Maps urine ACR (mg/g) to KDIGO albuminuria category A1–A3.
   Called by   : R02-assign-a-category
   Exported    : yes
   Notes       : <30=A1 (normal to mildly increased), 30–299=A2 (moderately increased),
                 ≥300=A3 (severely increased).
                 Source corpus: §1.3 — Evaluation of albuminuria.

* Constraints & Pitfalls
  _MAX_CYCLES recommended: N_patients × 3_rules × 1_agent × 10 = 30 × N_patients
  (typical project: ~10–30 patients → 300–900 cycles; default 10 000 is sufficient)

  - [ ] =type_element= slot is mandatory and must equal exactly "patient" (case-sensitive)
  - [ ] =egfr_ml_min= and =acr_mg_g= must be numeric (float); undef → R01/R02 return 0 silently
  - [ ] R03 depends on R01 and R02 both having fired — ensured by CONDITION guard
  - [ ] =ckd_stage= is a composed string (e.g. "G3aA2") — never test equality in downstream
        rules; always test =ckd_g_category= and =ckd_a_category= individually
  - [ ] G3 split: eGFR 45–59 → G3a, 30–44 → G3b — important for statin / treatment rules
